# 同一数据、不同优化初始化对照（前两种解析/拟合检查之后冻结）

补足上一轮有限样本检查的限制：原VFD ensemble是同一数据、不同训练seed，
上一轮每成员数据不同。本轮使用完全相同CFM样本和同一两参数模型，只改变初始化。

- 不改模型：v_c=v*+c0+c1(s−1/2)，真v*已知的人为可控基底，仍不是VLA。
- 数据n=[256,1024,4096]，每n有24个固定数据seed；每数据训练两个初始化seed。
- 初始化c服从N(0,.1²)，固定全批gradient descent，lr=.4，终点updates=[32,128,512]。
  所有终点报告，不从中选效果最大者。以同一数据的OLS解作优化参照。
- 原source默认11点评分，与已解析末端N(Kc0,1)的pairwise KL/MI比较；人口excess risk=c0²+c1²/12。
- 保留梯度正规式、每成员数据hash、初始参数、训练loss与OLS gap、最终参数；
  同一数组hash必须一致，完全相同初始化重复训练应逐项相等。
- 极小末端差异不能称有意义的KL排序：单独报告scores和scale；不以近机器精度的rank构造论文效果。
- 若普通收敛/多训练步即可消除该可控模型差异，必须报告，不把“早停”包装新机制。

没有机器人成功率、真实神经VLA ensemble或部署效果；不把本脚本计作方向已确定。
