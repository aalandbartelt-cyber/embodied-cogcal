# 有限拟合误差的接续检查（第一轮48条件之后冻结）

触发：第一轮反转可由传统Gauss–Legendre20点消除，不把换求积方法作为新核心。
本轮另检验实际使用learned field时的理论边界；保留第一轮原始文件，不把本计划称为第一轮事前计划。

基准为两个相同末端 N(0,1) 的精确OT边际场。a(s)=(1−s)²+s²，
v*(s,x)=(2s−1)x/a(s)。构造有限拟合偏差：

```
v_plus(s,x)  = v*(s,x) + ε(s−1/2)
v_minus(s,x) = v*(s,x) − ε(s−1/2)
eta(s)      = [a(s) − sqrt(a(s))]/2
x_plus(s,z)  = sqrt(a(s))z + ε eta(s)
x_minus(s,z) = sqrt(a(s))z − ε eta(s)
```

因为eta(0)=eta(1)=0，两个末端sample map逐样本均为z，真pairwise KL与epistemic MI均为0。
在原文均匀flow-time的CFM目标下，每模型相对v*的excess squared risk为ε²/12，可任意小。
这组场不满足精确OT人口最优场假设，不用它推翻原文连续定理；检查的是有限拟合误差下的实际代理分数。

## 固定检查

- ε=[0,1e−6,1e−4,.01,.1,1]全部保留；相同seed20261115/8个noise样本。
- 中心差分核对上述精确轨迹满足两个ODE，s=[.05,.25,.5,.75,.95]，step1e−6。
- 用原始InterVelDiff组件和默认11节点调用，核与独立公式一致。
- 均匀左网格与Gauss–Legendre N=[5,10,20,50,100,500]；连续截断上限b=[.9,.99,.999,.9999,.99999]。
- 被积函数为ε²[−4s²−1+1/(1−s)]，截断积分精确为
  ε²[−4b³/3−b−log(1−b)]。核独立quad，并报告终点发散的数学边界。
- 均匀左网格精确和为ε²[H_N−1−2(N−1)(2N−1)/(3N²)]，独立核离散结果。

不是机器人/VLA episode，没有真实神经网络、数据获取或转交效果，也不预设新算法。
该反例本身不能证明现有训练好的VLA存在有害的这类偏差；后续需要实际learned field及决策后果。
