## 实际新证据

固定官方 SO-ARM100 `a758567c3978dfeefe282ede0500085a48fe8f78`、原样
`so101_new_calib.xml` 的 `gripperframe`，seed 20261114，在每关节限位中央 60% 取 24 个配置。
只使用五个机械臂关节，不把夹爪开合计为位姿自由度。

- 24 个 6×5 Jacobian 均为秩 5；0.05/0.1/0.2 m 三种角速度尺度下结论一致。
- 五列逐一用中心差分独立核验。最大平移误差 `8.53e-11 m/rad`、最大角速度误差 `3.40e-10 rad/rad`。
  这是数值实现一致性，不是机器人物理精度。
- wrist_roll 的角速度在工具坐标中为约 `[-1, 0, 0]`。其同时使偏置工具点移动约
  `0.007903 m/rad`，所以不能将它等同于保持工具点位置不变的纯旋转。
- 在 0.1 m 尺度下，纯工具 x 轴旋转的局部最小二乘相对残差范围为 `0.000317–0.04111`；
  工具 y/z 旋转残差随配置明显变化。工具坐标下左零空间投影矩阵相对首配置的最大 Frobenius 距离为 `1.40061`。

因此，不能仅凭“五轴少一个自由度”就为这个模型指定一个固定缺失工具旋转轴，
或据此固定屏蔽某一旋转输出。缺失约束一般体现为配置相关的平移—旋转耦合。
这些局部一阶量不证明某个完整位姿全局不可达，更不证明某个抓放任务不可完成。

## 候选问题与最近邻

问题线索：**任务本身可完成时，保留完整末端位姿的示范增强是否仍会错误拒绝可行任务，
并系统性削弱生成数据覆盖及 learned policy？**

它与“任务根本不可达”“IK 没调好”“只要换低自由度机器人就新颖”不同。
目前只有运动学前提核查，没有生成任务失败、覆盖损害或策略损害证据。

| 最近邻 / 阅读范围 | 已有方法 | 对候选的影响 |
|---|---|---|
| [CP-Gen v1 §3、4.1–4.3](https://arxiv.org/html/2508.03944v1) | 以机器人/持物关键点约束技能，优化关节配置并连接运动；包含固定手—物变换假设 | “放弃完整位姿，保留任务关键点再求 IK”已有直接方法，不能作为我们的新核心 |
| [MoMaGen v1 §3](https://arxiv.org/html/2510.18316v1) | 用硬/软约束表述数据生成，包括可达性和碰撞等 | 泛称约束保持数据生成不是新点；不能只比较无约束 SE(3) replay |
| [Isaac Capture SO-101 1.4.x](https://nvidia.github.io/IsaacCapture/release/1.4.x/references/retargeting/so101.html) | 五轴 differential IK，位置优先、姿态 best-effort | 位置优先是现成简单强对照，换权重不能立项 |

当前读到的机器人配置为 Panda/xArm 等，未在这些配置中核到 SO-101；这不是全库无支持证明。
README 另指向 `adaflow-cpgen` 策略训练仓库。因此现有入口是强对照资产线索，**不是已适配就绪的 SO-101 基线**。

## 当前 go / no-go 和最小下一证据

**No-go：**固定轴 mask、位置优先 IK、关键点替代六维位姿、一般约束数据生成，均不作为核心新方法。
**仅保留条件问题：**现有强约束方法仍产生任务可行却被拒的场景，并影响数据覆盖/策略表现。

若继续，先构造有独立成功轨迹的源/目标任务对作为可行见证，而不是把优化器未收敛当不可达证明。
在相同源示范、相同目标场景、相同求解预算下，比较完整位姿 replay、位置优先 IK、
关键点/受约束优化和直接成功见证。保存所有拒绝/接受及原因。
只有受约束强对照仍暴露具体缺陷，才值得讨论新机制；否则这条线降为载体工具，不启动策略训练。

SO-101 真机的对应命题也是“同一可完成任务是否被保留无关约束的参考轨迹错误排除”，
最终还需相同物体关系、目标容差和抓放谓词的物理成功证据；本轮没有真机结果。
