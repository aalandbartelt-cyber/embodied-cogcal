# SO-101 位姿重定向：先检查前提

本轮只做离线运动学核查，不训练策略、不改变接触模型或原始 TPSC 资产。

触发线索：作者博客将五自由度限制描述成缺少固定工具接近轴旋转，并报告六维轨迹重定向/IK。
先不采信这句轴解释，也不把博客的少量非配对运行当机制证据。

检查固定官方 SO-ARM100 revision a758567c3978dfeefe282ede0500085a48fe8f78，
`so101_new_calib.xml` 的 `gripperframe`。固定 seed 20261114，取关节限位中央 60% 的 24 个配置；
配置只用于几何，不做碰撞可行/物理任务声明。先写下采样方式再计算，不按结果选姿态。

1. 计算五轴 6×5 几何 Jacobian，排除夹爪开合；以中心差分独立核对平移/旋转两块。
2. 以 0.05/0.1/0.2 m 三种事先指定的特征长度统一角速度/线速度的尺度，避免无说明地混合单位。
3. 记录秩、工具轴纯旋转的最小二乘残差，以及工具坐标下左零空间的变化；不把局部一阶残差当全局不可达证明。
4. 核查 wrist_roll 的世界角速度方向与工具 frame 各轴的对应。

解释门槛：确认缺一个自由度不等于发现新问题；模型约定不同也可能造成博客轴表述差异。
只有“任务本身可做、增强后的参考不可行”及实际数据/任务后果都验证后，才进一步讨论选择偏差。
CP-Gen、MoMaGen、Isaac Capture 的位置优先 IK 是必须比较的直接近邻；简单受约束 IK 足够则停止新方法主张。
