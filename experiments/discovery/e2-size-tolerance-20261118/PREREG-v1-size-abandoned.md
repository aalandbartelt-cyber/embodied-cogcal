# E2 预注册：同 δ、不同物体宽度，成功率是否随宽度变化

状态：**在任何 episode 跑之前写定**。写定后不改条件、不改端点、不改排除规则。
上游：`docs/direction-20261116b/F1_POLICY_ERROR_BUDGET.md` §2 H1、§3 E2 增补；
`experiments/discovery/e1-delta-mechanism-20261117/E1P_RESULT.md`（过渡带 14–19 mm）。
日期：2026-11-18。执行者：lead（无外部实验者）。

## 1. 要回答的问题

E1′ 只证明"成功率随 δ 单调下降"，没证明存在**容差尺度** τ：若成功率只依赖 |δ|，
则 `r/τ` 里的 τ 是空转量，H1 塌缩不成立，F1 的"无量纲数"主张没有基础。

E2 只测一件事：**固定 δ，改物体宽度 W，成功率是否变化。**
- 若随 W 变化（更宽的物体更差），则存在与 W 相关的容差尺度，H1 可继续；
- 若完全不变，则 τ 不能从几何宽度进入，H1 的几何式必须放弃，方向需换轴。

这是 H1 的**必要条件**检验，不是充分条件：E2 通过不代表塌缩成立，只代表"值得做 E3 的 x50 拟合"。

## 2. 条件（全部写死）

| 因子 | 水平 | 说明 |
|---|---|---|
| 物体宽度 W | 20 / 28 / 36 mm（半宽 0.010/0.014/0.018 m） | 28 mm 为训练分布；两侧各 ±8 mm |
| 横向偏移 δ | 14 / 18 mm 中心，每 episode 在 ±0.5 mm 内均匀抽取 | 落在 E1′ 过渡带内；偏移沿 (x,y) 等量施加，同 E1′ |
| 种子 | 12850–12869，20 个，**六个条件共用同一组** | 配对；不与 E1′（12800–12819）重叠 |
| 立方体中心高度 | z = W/2（贴桌） | 由宽度决定，不是自由参数 |
| 其余 | 冻结 ACT checkpoint、carrier 字节码、285 步、30 fps、100/30 | 与 E1′ 完全一致 |

共 6 条件 × 20 = 120 episodes，顺序执行，单 sim。

## 3. 端点

- **P1（主）**：合并两个 δ 后，`成功率(W=20) − 成功率(W=36)`。one-sided Fisher 精确检验，
  α = 0.05；差值以 pp 报告并给 95% Newcombe 区间（实现用 bootstrap 配对种子）。
- **P2（序）**：Cochran–Armitage 趋势检验（宽度序 20<28<36，方向：越宽越差），合并 δ，
  one-sided，α = 0.05；并报告每个 δ 分层内的方向（同向层数）。
- **P3（次）**：每尺寸在 r 轴上的经验 x50（logistic 拟合，仅当该尺寸同时有成功与失败）；
  只报告，不设判据（20 个点/尺寸不足以稳定拟合）。

## 4. 决策规则（写死，不事后改）

- **PASS（宽度有效应）**：P1 差值 ≥ +10 pp 且 Fisher one-sided p < 0.05，且 P2 方向正确
  （趋势 p < 0.10）。→ H1 必要条件成立，进 E3（三尺寸 x50 塌缩拟合）。
- **FAIL（宽度无效）**：P1 差值 ≤ 0，或 P1 的 95% 区间上界 < +10 pp。→ 放弃几何 τ 进入 H1，
  方向文档改为"经验容差、不做几何式"，并把 F3 提为备选主选。
- **INCONCLUSIVE**：其余情况（例如差值 +6 pp、p = 0.2）。→ 不改协议、不追加条件，
  在结果文档里写明"120 集不足以分辨 <10 pp 的效应"，由用户决定是否加种子到 40/条件。

## 5. 排除与完整性

- 不按结果排除任何种子或条件；全部 120 集进分母。
- 运行前写 contract（prereg sha、checkpoint sha、carrier sha、种子、条件表）；运行后

## 6. 已知混杂（写进结果，不藏）

立方体只有**一个 geom**（`cube_visual`，同时是碰撞体与渲染体）。改 W 会同时改外观，
因此 20/36 mm 对策略也是外观分布外输入。E2 因此**不能**区分"几何容差"与"外观 OOD"。
PASS 只说明"宽度（或与其绑定的外观）在固定 δ 下改变成功率"，E3 才需要把两者解耦
（加一个仅渲染的视觉 geom，物理体仍为 W）。这是本预注册承认的局限，不构成事后改判据的理由。
