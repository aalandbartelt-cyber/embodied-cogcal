# PREREG — E1′ 连续位移机制 pilot（连续随机化 δ）

日期：2026-11-17（本地）｜状态：**冻结后执行**｜GPU：0（MuJoCo CPU，3.4 s/episode）
上游：`docs/direction-20261116b/F1_POLICY_ERROR_BUDGET.md` §3 E1 重设计；
`experiments/discovery/e0-error-budget-20261116/E0_RESULT.md` §2–3。

## 1. 为什么要重设计 E1

E0 证伪的不是"误差有结构"，而是"计划空间残差 `r` 能预测成败"：7 个常数条件把 140 集压成
7 个点，条件内 `AUC = 0.501`，`ΔAUC(r − |δ|) = −0.001`。同一批 trace 在执行空间给出了第一次
条件内信号（d=15，n=20，事后）：闭合前物体位移 `obj_pre` 的 `AUC = 1.00 (p<0.0001)`，
计划-执行缺口 `AUC = 0.99`。但那是**一个条件、事后、n=20**，且 δ 与条件完全共线，
无法区分"位移越大越难"和"接触过程把物体推走"。

所以 E1′ 只回答一个问题：

> 把 δ 连续化并让它在一段区间内变化之后，`obj_pre` 是否仍在 **δ 内部** 保留判别力？

这不是 H1（跨尺寸塌缩）的检验，也不是方法有效性主张。它只决定 F1 是继续做"执行空间容差消耗"
这条线，还是降级为"一条经验曲线"。

## 2. 设计（冻结）

- 位移 `δ = (d, d)` mm（对角，x=y 同向），`d ∈ [0, 30)` 连续。
- 10 个 3 mm 分箱：`d = 3·b + U(0,3)`，`b ∈ {0..9}`；每个 (b, seed) 的 `U` 由固定 RNG
  `numpy.random.default_rng([20261117, b, seed])` 给出，**先写进 contract 再跑**，不可事后改。
- 种子：12800–12819（fresh，与 gain-scan 的 12700–12719 不重叠），每箱 20 集，共 200 集。
- 其余完全复用 2026-11-17 gain scan：同一 checkpoint `final-20000.pt`、同一 carrier 字节码、
  同一 XML（`XML_SHA256`）、30 Hz、285 控制步、chunk 100/执行 30、两路 RGB + 实测 q。
- 不训练、不微调、不采集新示教、不买硬件。

## 3. 端点（跑之前固定）

**主端点（G1′）**：分箱内（within-bin）`obj_pre` 对 `task_success` 的判别力。
`obj_pre = ‖xyz(t_cross) − xyz(0)‖`，`t_cross` = 夹爪首次闭合到阈值 0.20 rad 的时刻，
`xyz` 取自 `-physics` 的 2000 Hz 记录（与 E0b/E0c 同一口径）。

- 只统计**成败混合**（成功 ∈ [3, 17]/20）的箱为"有判别功效"；全成功/全失败箱记为无功效，
  不从分母里删除。
- 分层 AUC = 各有效箱 `AUC(−obj_pre)` 按 `n_pos·n_neg` 加权平均。
- 判据 **PASS**：分层 `AUC ≥ 0.75`，且分层 bootstrap（按 seed 重采样，10000 次）95% 下界 `> 0.5`，
  且有效箱数 `≥ 2`。
- 判据 **FAIL**：分层 `AUC < 0.65` 或下界 `≤ 0.5`。其余为 inconclusive，不做二次切分。

**次端点**：
1. `ΔAUC = AUC(−obj_pre) − AUC(−|δ|)` 在分层口径下；报 CI。它回答"`obj_pre` 是否只是 δ 的代理"。
2. 成功率对 δ 的曲线（10 个箱的中位数与四分位）；用于判断任务在 0–30 mm 上是否单调可做。
3. 计划-执行缺口 `‖p_exec − p_plan‖` 的箱内 AUC（与 E0b 同口径），作为机制的另一面。

**明确不做的**：不声明跨尺寸塌缩（τ 未变化，尺寸随机化留给 E2）；不声明可补偿（那是 E5′）；
不声明新方法优于基线（没有方法）。

## 4. 排除与完整性

- 不按结果排除任何种子；不因"看起来异常"重跑某集；失败物理导致的 worker 崩溃按原样记录并中止该箱。
- 每箱写 `contract.json`（含 prereg sha、checkpoint sha、carrier pyc sha、δ 抽样表、seed 表），
  每集写 `episodes.jsonl` + `*.trace.jsonl` + `-physics/*.npz`，全部记 sha256。
- 复检：XML sha 与 MuJoCo 版本在启动时断言；`verify_e1p.py` 复算 sha 与箱内种子集合。

## 5. 解释边界（写进论文时必须保留）

即使 PASS，结论也只能是："在冻结策略、单一任务、单一物体几何下，闭合前的物体位移在 δ 内部
仍预测成败，且比 δ 本身多信息。" 它不是新机制，不是通用水位，也不是"SOTA"。
若 FAIL，则 F1 的执行空间假设只剩 d=15 一个事后分层，方向降级为诊断工具，
并按 `RESEARCH_DIRECTION_DECISION_20261116.md` 的重开条件回退。
