## 改变下一动作的发现

| 记录 | 直接可见事实 | 科学边界 |
|---|---|---|
| 失败226、232 | 多个后段网格中，环仍近原取环槽，未显示搬到桩上的过程 | 不能证明所有时刻均未抓起或因机械堵转 |
| 失败231 | 9秒环在桩上方，12秒起在底座后方边缘外，末段没有完成套桩 | 不知道是释放、滑移、碰撞、抓持失稳或坐标错位 |
| 失败233 | 多次网格中环随爪到桩附近，另一些时点在右槽/底座外，末帧右槽 | 不能把它归为单纯抓取前失败 |
| 失败234、235 | 环离开原槽后到另一槽，后段仍在另一槽附近 | 搬起不等于保持成功，表面动作也不识别根因 |
| 成功229、236 | 中途也出现环到另一槽，后来又到桩上并结束 | 最终结局不能直接充当每个时点的即时故障/必须干预标签；中途偏离不意味着必须立即干预 |
| 成功225、227、228、230 | 固定末帧与作者成功标签相容；225的稠密复核已有多次接近过程 | 不是盲法独立复标，也不说明每次中间抓持都成功 |

因此：**先前“抓取区域停留”不足以统一解释该任务失败，也不足以指向某一种记忆或补偿。**
更密视频仍不能补相机曝光/动作真实同步、对象6D姿态、接触力、校准或反事实分支。
12条初态未配对，按结局分层，不能据此估计总体失败比例/成功率、做因果差异或帧级统计。
末帧有作者成功裁剪影响，3秒绝对网格也不等于公平时域的性能评估。
这不否定用episode结局监督“最终是否失败”的预测器；被区分的是最终结局、当前物理故障与干预价值。
