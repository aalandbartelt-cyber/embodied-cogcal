## 目的

把 C4 的 oracle θ 换成**只从 RGB 估计的 θ̂**，并在冻结策略、330 步预算下复测补偿。
E7A 已把预算与剂量收口（10° 足够、330 步解除释放尾），本实验只回答一个问题：
**θ 能不能从图像里估出来，估出来之后闭环还成不成立。**

## 估计器（先冻结）

- 输入：仅 top view RGB，512×512；颜色阈值分割橙色立方体，取 200–5000 px 的最大连通域；
- 对掩码做 0–90° 最小面积矩形搜索（步长 0.1°），取 `yaw = wrap90(90° − angle)` 到 `[-45°, +45°]`；
- 不使用 object qpos、分割缓冲、成功标签、策略输出或任何特权状态；
- 估计器相机是独立的 512 px 传感器；冻结策略仍只接收自己的 `2×128×128` RGB 与 `q_rad`。

## 假设与判定

- **H1（静态精度）**：在 yaw ∈ (−45°, +45°)、步长 2.5°、5 个 reset seed（12850–12854）上，
  `max |θ̂ − θ| ≤ 1.5°`，`mean |θ̂ − θ| ≤ 0.5°`。若超限，先修估计器，不跑闭环。
  **边界说明（预注册修正，2026-11-18，在看到 ±45° 端点失败后）**：正方形截面在 ±45° 处
  恰好相差 90°，是同一物理朝向，silhouette 不可区分；估计器对二者都返回 +45°。
  因此 H1 的区间改为开区间，±45° 不作为可识别点；这不是精度失败，而是 90° 对称性的定义域边界。
- **H2a（主闭环，+15°）**：yaw=+15°、δc=1.0 mm、330 步、估计偏置（非 oracle），
  20 seed 中成功 **≥18/20**；点预测 20/20（E7A D330 为 20/20）。
- **H2b（探索，−15°）**：同条件但 yaw=−15°，成功 **≥18/20**；这是符号与策略对称性的探索臂，
  不通过也不推翻 H2a。
- **H3（特异性，0°）**：yaw=0°、估计偏置应≈0；成功 **≤5/20**，与 E5″ D0（1/20）同侧，
  证明估计器不会在无偏航时注入有效偏置。
- 所有闭环臂固定 330 步；不跑 285/320，避免释放尾混杂。

## 边界（预先声明，不事后补）

- 立方体是正方形截面，silhouette 有 90° 别名；本估计器只在 **±45°** 内定义，
  不声称能处理 >45° 或 90° 对称等价类。
- 颜色阈值针对本场景的橙色立方体与固定光照；遮挡、反光、换物体未测。
- 单策略、单物体、单场景；−15° 臂是探索，不进入主 claim。
- 估计器误差是**角度**误差；闭环成功还受抓取/释放影响，不能把失败全部归给估计器。
