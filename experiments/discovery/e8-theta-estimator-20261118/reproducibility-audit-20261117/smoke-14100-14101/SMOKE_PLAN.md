# E8 负偏航运行准备：非确认性 smoke

日期：2026-11-17 Asia/Shanghai。此记录在启动模拟之前编写。目的仅是验证既有 `rollout_e8.py` 在独立 smoke 种子上的执行、数据完整性及两臂初始状态配对，不检验新方法效果或科学假设，不作为正式预注册的证据。

条件：使用现有 E8 脚本的 `--tag smoke`，源 yaw=−15°，固定 q5 偏置分别 0°、−7.5°；种子 14100 与 14101，每臂两集、总计四集；330 控制步。两臂不包含在候选正式样本 14000–14079 中。种子清单检查仍有覆盖缺口，不能断言这些种子在所有外部历史中未用。

输入、输出、物理和策略采样口径沿用现有 E8。固定剂量臂仍执行 RGB 估计器并有 gross-error 门槛；它可能导致中止，不能当作纯固定剂量最终方案。旧脚本合同中的 E8 身份与 E8 预注册哈希仅描述旧脚本固有行为，不表示本 smoke 获 E8 预注册。任一运行失败保留 stderr 与部分产物，不将技术故障算任务失败，不按表现挑选或替换种子。

核查：逐条核对 contract、种子、330 个控制步、结果与物理哈希，比较同 seed 的初始机器人 q、源/目标位置、初次图像 hash、偏置命令；检查有限值、穿透限制；无误才说明此条件下的流程 smoke 已完成。此检查不能证明全部隐藏 RNG 状态相同，亦不能推断跨设备 GPU 确定性或真实运行的可重复性。
