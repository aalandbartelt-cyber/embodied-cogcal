# 方案草稿：负偏航下固定剂量的独立复核

日期：2026-11-17（上海时间）
状态：**草稿，未冻结、未执行；不构成已完成的预注册**。在固定新 runner、种子审计及验收检查之前不得启动确认性数据采集。文件名中上游 `20261118` 是既有目录标识，不作为本次日期。

## 1. 问题与先前证据

同一冻结 ACT 策略、28 mm 立方体、源 yaw = −15° 时，固定 q5 注入 −7.5° 是否优于 0°？反向是否成立？E8 的相同 20 seeds 事后诊断给出 0° 17/20、−7.5° 18/20、−10° 15/20、估计约 −15° 13/20。这些结果用于选定比较，不是本研究的确认数据。该研究不证明全局最优剂量、方向不对称机制或跨场景有效性。估计接近 −15° 与精确固定 −15° 不是完全相同的干预。

## 2. 设计与冻结对象

- 四臂同一批 **80 个全新场景 seed 配对**：yaw 固定 −15°，q5 命令固定注入分别为 0、−3.75、−7.5、−15°。一个 seed 每臂恰好一个 episode；不按结果补 seed。共 320 个正式 episode。臂的执行顺序在采集前按固定算法生成并记录，所有臂不因中途成功率停跑。
- 候选正式 seed 14000–14079；候选 smoke seed 14100–14101。**尚未验证唯一性**：启动前机器核对仓库所有可读取的历史 contract、逐集文件、训练/验证 seed 清单和已知外部记录；不能证明确属未使用，则选择并记录无冲突的新连续块，重新冻结本协议。smoke 永远不进入统计。
- 用 E8 相同 `final-20000.pt`、载体/XML、推理环境、源位姿生成和终点；源偏移每轴相同 `delta_mm = 1 + U(-0.5,0.5)`，按 E8 `delta_mm_for(-15,1,seed)` 产生。臂间同 seed 的 reset 状态、源位姿、目标、随机数状态、delta 必须经验证相同，仅目标 q5 注入不同；不以 seed 标签一致代替核验。
- 统一 330 control steps、30 Hz、chunk 100/execute 30，冻结注入时点、上下限裁剪、求解器与接触设置。记录每个目标 q5、执行命令、实际关节状态、裁剪和碰撞，保留原始轨迹与 hash。0° 采用 fixed 0 与 fixed 其他臂同一路径；如改为 zero 路径需在冻结前确认两者等价并写明。
- E8 `rollout_e8.py` 当前 `--tag e8` 强制 12850–12869，`smoke` 至多 2 集；**不能直接用它冒充正式运行器**。须创建独立、版本化 runner，在保留物理与成功口径的基础上显式支持本协议 seed 块、四剂量、完整预注册及源代码 hash，新增配对契约检查和不同输出目录；不得改写 E8 的既有轨迹或数据。
- 本方案仅研究模拟中的固定剂量，给出真实 yaw 的条件已知；不声称 RGB 估计器或真机的部署结果。统计单元为配对 seed；确定性结果的推广范围仅为此处指定 reset 随机分布与模拟平台。

## 3. 主终点与判定

- 主终点为 E8 同义 `task_success`，沿用 carrier 完整定义，需在运行前固定其源代码及阈值 hash；不得把 `held`、`placed` 或 `released` 任一单项代作任务成功。主比较为 **−7.5° 减 0°** 的配对成功率差 Δ。记录两种不一致数 b（−7.5 成功、0 失败）与 c（反向）。
- 双侧精确 McNemar 条件二项检验，零假设 b 和 c 等概率，显著性 α=0.05；若 b+c=0，p=1。固定报告 Δ=(b−c)/80、b/c、精确 p、两臂成功数，以及按 seed 整对重采样的 percentile bootstrap 95% 差值区间（20,000 次，NumPy PCG64，分析随机种子 20261117，双端 2.5%/97.5% 分位，所有重采样均为 Δ=0 时区间 [0,0]；此区间是描述性的）。
- p<0.05 且 Δ≥0.10：支持“−7.5° 在此条件下提高成功率”；p<0.05 且 Δ≤−0.10：支持“0° 在此条件下优于 −7.5°”。其余为**未定论**；显著但差值不足 10 个百分点单独披露为统计差异、小于实践阈值。不得由 p≥0.05 推断等价、零剂量最优或无效，也不得因两者差异方向推断其全剂量最优。
- −3.75° 与 −15°、任意剂量排序、剂量曲线、最优剂量、因果机制均为**探索性**，给出配对差值、置信区间和原始对照，p 值标为未校正；不得升级成确认结论。若今后要主张最佳剂量或非劣，须另行预注册独立种子与多重比较/等效界。

## 4. 样本量与检测能力

每臂 n=80 为固定预算而非保证有足够统计功效。以双侧精确 McNemar α=0.05、配对不一致概率 `(b/n,c/n)` 假定为 (0.20,0.05) 时，精确枚举的检验功效约 0.737；(0.15,0.05) 时约 0.437；(0.10,0.05) 时约 0.134。再同时要求观察差值绝对值至少 0.10 时，双向联合判决概率分别约 0.736、0.433、0.120。它们依赖未经确认的配对概率，不是数据所得功效。E8 实测边际差仅 1/20；本设计很可能不能检出小差异，也不足以确认等价。不能在观测结果后改变 n 或阈值，未来需要更精确估计时独立设计后续实验。
