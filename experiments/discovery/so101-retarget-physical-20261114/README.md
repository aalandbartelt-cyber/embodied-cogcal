# 位姿重定向物理筛查：两种普通 IK 均 4/4

2026-11-14。**本轮没有观察到预想的任务损害；停止将这条线作为当前核心方法候选。**
这是固定物理载体上的特权脚本生成器检查，不是 learned policy、VLA、CP-Gen/MoMaGen 复现或真机结果。

## 为什么做，以及实际改变了什么判断

上一轮[24个配置的运动学核查](../so101-retarget-screen-20261114/README.md)发现，
不能把五轴少一个自由度等同于固定缺失某个工具旋转轴。
但 Jacobian 秩不足本身不证明真实任务会受害。因此本轮先为每个任务取得物理成功见证，
再检查完整位姿重定向是否真的比普通方向约束差。

预先固定的四个保守工作区布局中，两种方法均完成抓取、双指抬升、放桌与释放。
**没有证据支持继续为本工作区开发新的约束选择方法，也没有数据过滤/覆盖或策略损害结果。**
不在看到 4/4 后继续加大扰动或收紧成功阈值来制造失败。

  两种 identity 的最大命令差均为 `1.11e-16 rad`。

## 证据边界

1. 锚点参考来自源关节命令 FK，沿用固定特权技能分段，不是从真实执行状态恢复完整源轨迹。
2. 简单方向约束是独立普通 IK 对照，不是忠实 CP-Gen 实现；不以本结果评价那些原方法的性能。
3. 仅四个保守布局、同一指垫/摩擦模型，不能排除更广工作区或不同任务出现问题。
4. 物体真值只供生成器/评估；执行过程中未传送、焊接或重写物体姿态，没有 RGB 策略输入或学习训练。
5. 该接触模型尚未做真实 SO-101 标定，因此没有同题真机结果。

本轮只说明：当前候选的“任务损害”证据门槛未过，简单对照足以完成已测任务。
与已有 CP-Gen/MoMaGen/位置优先 IK 的重合仍存在，不把实现管线或低成本平台改名为新方法。
完整选题目标仍 active；后续应寻找别的具体问题，不重启此处的小模型/扩大扰动以保留题名。
