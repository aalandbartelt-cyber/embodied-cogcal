# 分析（analysis）

W2 的分析契约在这里落地。当前只列必须提前定死的事项，避免看到结果后再改口径。

## 分析契约（待 W2 冻结）

- **实验单位**：episode；每个任务、每个条件至少 50 episodes（W1 冒烟除外）；
- **偏差指数**：如何由探针行为计算（方向、幅度、相对对照组的偏移）；
- **条件**：模型 × 偏差类型 × 强度 × 种子；
- **主指标**：偏差指数、任务成功率、补偿后恢复率、正常任务性能保持率；
- **统计**：配对检验、效应量、Wilson 置信区间、多重比较校正；
- **误差线**：明确是标准差、标准误还是置信区间；
- **排除规则**：渲染失败、环境异常、超时如何记录与处理；
- **数据完整性**：原始 episode 日志、随机种子、检查点、配置全部落盘。
