# 偏差探针（probes）

W2 开始填充。当前只记录设计约束，不写实验代码。

## 一个探针必须满足

1. **有可判定的正确答案**：不是“看起来合理”，而是能自动判定成功/失败或偏差方向；
2. **受控变量**：一次只改变一个因素（初始指令、目标位置、遮挡比例、频率分布等）；
3. **保留未见变体**：训练/设计用一套，最终测试用未参与设计的变体，防止记忆化；
4. **可量化**：每个 episode 输出偏差指标，而不仅是成功率；
5. **可复现**：任务生成参数、种子、LIBERO 套件版本全部记录。

## 候选偏差（来自主记录，待 W2 收敛为 2–3 类）

| 偏差 | 探针思路 | 主要风险 |
|---|---|---|
| 锚定效应 | 给一个错误但看似合理的初始目标/数量提示，测最终动作向锚点偏移的程度 | 提示可能被模型忽略，需强/弱两档 |
| WYSIATI（眼见即为事实） | 部分遮挡或目标替换，测模型是否仍执行原指令 | 与普通鲁棒性测试混淆，需要对照 |
| 可得性/频率偏差 | 操纵训练分布中物体/位置的频率，测未见组合的选择偏差 | 需要足够多的组合与 held-out 变体 |
| 损失厌恶 | 可恢复失败 vs 不可恢复失败的探索行为 | 在仿真中定义“损失”较困难 |
