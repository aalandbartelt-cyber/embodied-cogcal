# 研究路线：B 方案最小科学闭环

## 研究主张

本项目先研究 VLA 的决策层系统性偏差，不把接触控制、强化学习、真机和空间机器人
同时纳入第一版实验。核心问题是：

> 在受控的 LIBERO/MuJoCo 任务中，VLA 是否存在可重复的锚定效应和 WYSIATI 偏差；
> 这些偏差能否被量化，并通过条件化补偿恢复受扰任务性能，同时保持正常任务能力？

## 最小闭环

1. **测量**：先实现锚定和 WYSIATI 两类探针，每类都包含中性对照、强度梯度和未见变体。
2. **建模**：冻结偏差指数、任务成功率、补偿后恢复率和正常任务保持率的定义。
3. **补偿**：先做规则级补偿；只有规则闭环成立后，才考虑轻量门控或慢通路审议。
4. **验证**：比较原始策略、CoT/反思对照和本文补偿方法，报告配对统计、效应量和
   Wilson 置信区间。
5. **复现**：保存任务生成参数、模型检查点、随机种子、原始 episode 日志、配置和视频
   的映射关系。

## 实验分层

- **Pilot**：一个模型、少量任务和少量 episode，只判断探针是否产生稳定效应。
- **正式实验**：一个模型完成两类偏差的完整矩阵；第二模型做验证性复现，不在第一天
  把所有条件翻倍。
- **失败条件**：若某探针无效，删除或重做；若补偿降低正常任务性能，优先修正门控，
  不直接引入 RL。

## 仿真到真机

### 阶段 1：仿真（论文主结果）

LIBERO/MuJoCo 负责探针、补偿和统计主结果。此阶段的目标是形成可投稿实验包，包含
失败/成功 rollout 视频和可追溯 source data。

### 阶段 2：低成本真机（外部效度验证）

优先考虑 SO-101/LeRobot 生态：官方开源仓库提供 BOM、组装说明、LeRobot 接口以及
SO-101 的 URDF/MuJoCo 描述，适合先仿真后真机。真机阶段只验证少量低风险任务，例如
桌面抓取、颜色/物体替换和遮挡条件下的动作恢复；不把小型舵机臂结果表述为工业精度或
大模型通用能力证明。

myCobot 280 的优点是成品化程度较高、Python/ROS 接口成熟；缺点是有效载荷和工作空间
较小，当前主线需要额外做动作接口和数据格式适配。它适合作为“快速打通控制链路”的
备选，不作为第一选择。

## 2027 扩展

在认知层闭环稳定后，再扩展学习型残差、POMDP 仲裁、接触层柔顺调制、远程真机和空间
机器人应用。每次扩展都必须复用同一套偏差定义和日志格式。
