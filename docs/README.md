## 3. 证据等级

`reference/` 下的文件是二手笔记/综述/教程，不是一手论文。写作时：

- 方法、公式、数值结论必须回到原始论文或官方仓库；
- 引用笔记时只用于建立直觉、术语和阅读线索；
- 笔记里的产业数字（成功率、延迟、参数量）如无原始出处，不进入论文表格。
