## 1. 一条被现有数据提前指出的现象

`experiments/discovery/gain-scan-20261117/`（140 episodes，7 条件 × 20 配对种子，
478 s）已经测出：

| \|δ\| (mm) | 计划抓取位移 (mm) | 计划残差 r (mm)* | 成功率 |
|---:|---:|---:|---:|
| 0 | — | 0 | 18/20 |
| 3.5 | 2.60 | 1.2 | 17/20 |
| 7.1 | 4.65 | 3.1 | 20/20 |
| 14.1 | 6.60 | 9.1 | 19/20 |
| 21.2 | 6.70 | 15.3 | 10/20 |
| 28.3 | 6.43 | 22.5 | 0/20 |
| 42.4 | 6.21 | 37.1 | 0/20 |

\* r = \|δ − Δp_plan\|，由报告中的 planned disp. 与 angle to δ 反算，FK 投影，非实测执行位置。

两个事实同时成立，而且**互相独立**：

1. **响应饱和，但方向在变。** 计划位移上限 ≈ 6.2–6.7 mm，可是偏离 δ 的角度从 12.8° 涨到约 30°。
   也就是说：误差不只是"追不上"，还是"追歪了"。`analyze_gain_decomposition.py` 的结论是
   执行端位移接近满幅但角度大、计划端长度不足但方向较好——**这是 2×2 映射，不是标量增益**。
2. **重复性远高于准确度。** 同一 seed 重跑，per-seed 计划增益复现到 max |Δ| = 1.19e-4；
   而跨初始条件，同一条件内 per-seed 增益在 0.033–0.400 之间（12×）。即：
   给定初始条件，这个策略的偏差是**确定的**；跨条件，它系统性变化。

把 (2) 翻译成工业语言：这不是"噪声大的传感器"，这是**重复性 0.1 级、准确度 1 级的机床**。
工业界对这类机器的标准答案是众所周知的：**不追求准确度，而是测出系统误差并补偿**。
而学术界对冻结策略的标准答案目前是"再加一个网络去修"——那是另一条路。

这就是本轮的主假设来源：**冻结视觉运动策略的系统误差有可测结构，结构决定它可不可补偿。**

## 3. F1：策略误差预算（推荐）

**核心问题**：冻结策略的失败，能否由一个**部署前就能算出的无量纲数**预测？

**机制（待检验，非既成结论）**：
成功率由 **r/τ** 决定，其中 r = 计划抓取点相对目标物体的残差（**首帧可见，执行前可得**），
τ = 该物体在该夹爪下的几何容差（≈ (有效指距 − 有效物宽)/2，**几何可得**）。
若成立，则存在一个门槛 κ ≈ 1：r < τ 成功，r > τ 失败，且**不同物体尺寸的成功曲线在 r/τ 上塌缩**。

**为什么这不是同义反复**：因为 τ 由几何**独立测出**，r 由首帧计划**独立测出**，
两者都不使用成功标签。用它去预测另一组实验（位移扫描）的成败曲线，是一次真正的预测。
"成功率随误差增大而下降"是同义反复；"这条曲线的位置由 τ_geom 定量给定、且跨尺寸可塌缩"
不是。

**为什么它不是被关掉的那条线**：它不训练、不改模块、不换任务。它测的是一个
**任何冻结策略都有的量**，产物是判据和协议，不是网络。

**最近邻与剩余差**（详见 `NOVELTY_PACKAGE.md`）：

| 最近邻 | 它做了什么 | 它没做 |
|---|---|---|
| 2611.17658（锚定/折扣） | 解释观测折扣机制，post-hoc α 与成功率相关 | 无补救、无定量预测 |
| APEX（NTU） | 修 policy→controller 的执行差 | 需黑盒控制器，非"部署前预测" |
| RTCF 2608.04527 | training-free 检索式 test-time 修正 | 无误差结构、无容差、无边界 |
| Active Vision（ICCAS 2026） | 主动移动相机对齐训练分布 | 只处理观测侧，不量化可补偿性 |
| tolerance-guided insertion 2108.02303 | 把容差当策略输入 | 不测冻结策略的容差，无塌缩定律 |
| BC-of-MPC 2606.00383 | 报告"严格容差下的精度差距" | 只报告现象，无定律、无预测 |
| SO-101 failure benchmark 2606.08881 | 失败分类学 | 分类不预测，无几何容差量 |

检索层面：arXiv `all:"grasp tolerance" AND all:"policy"` → **0 条**；
`all:"task-space error" AND all:"behavior cloning"` → **0 条**；
GitHub `robot policy error budget` → **0 个仓库**。这是"名字还没被占"的弱证据，
不是查新结论。

**现有资产**：固定 checkpoint（18/20，审计通过）、确定性 rollout（1e-4 级复现）、
trace/physics/hash 保留流程、140 条已冻结 gain-scan 数据、3.4 s/episode 的算力节奏。

**成本**：Day 0 纯分析（0 rollout）；全套 F1 实验 ≈ 1000 episodes ≈ 60 min GPU + 1–2 天编码。

**成果形态**（按可行性排序）：
1. RA-L / ICRA 短文：**"一个无量纲数预测冻结模仿策略的部署成败"** + 开源审计工具；
2. 学位论文一章：把"可校正性判据"作为认知科学侧的主张（几何-统计偏差可补偿，门控-语义偏差不可）；
3. 工程交付物：`peb` 工具包 + "部署容差卡"（LeRobot 用户可直接跑）；
4. 中文核心/会议：工业精密补偿 × 认知偏差的框架文（无新实验也可成立，但下限低）。

**风险**：① 塌缩不成立（尺寸把任务推出分布，r 与 τ 混杂）；② τ_geom 过于粗糙，斜率偏离 1；
③ 审稿人认为"精度-容差"是工程常识。前两条有明确 kill 判据（见 F1 设计文档），
第三条靠"预测而非报告"来挡。

## 4. F2：偏差场的可辨识性（F1 的机制章，不单独立项）

单独看，这是"估计一个 2×2 增益并求逆"，与 APEX / 动作仿射修正器 / hill-climbing 生态正面相撞
（`afinitus/awesome-hill-climbing` 已经把"residual/steering/test-time verifier"编成目录，
说明这是一个**有名字的拥挤赛道**）。只有当它服务于 F1 的"可补偿性判据"时才有独立价值：
补偿成功的条件 = 偏差场在可观测量上可辨识 + 未被门控截断。
所以 F2 在 F1 里以两个实验存在（E3 可辨识性、E5 门控边界），不单独立项。

## 5. F3：认知偏差框架迁移到 LLM 智能体（备选轨道）

**为什么列**：不需要硬件、不需要 GPU、单篇周期短；"System 1/2 + 锚定 + 过度自信"在
agent 评测里是活文献；用户已有的中文写作与图示资产可直接迁移。
**为什么只是备选**：进入门槛低 = 竞争者多；且它离开"具身"主轴，学位论文叙事要重写。
**若启动的最小形态**：把 F1 的"可校正性判据"抽象成 agent 版——同一批任务，分别注入
几何型偏差（工具参数偏移）与门控型偏差（检索失败），检验"可校准性"是否也二分。
**裁决**：F1 的 G1 门槛不过时再启动，不与 F1 并行。
