## 结论先行

**推荐 F1「策略误差预算（PEB）」**：用一个部署前就能算出的无量纲数 `r/τ`
（计划残差 / 几何抓取容差）预测冻结策略的成败，并用"几何型 vs 门控型"判定它可不可补偿。

理由只有三条，都可被单一实验杀死：

1. **已有数据已经指向它**——同 seed 复现 1.19e-4，跨条件 12× 差异：这个策略是"重复性 ≫ 准确度"，
   和工业机床同构，而工业界对这类机器的标准答案就是"测出来再补"。
2. **它躲开了上一轮的 no-go**——被关掉的是"换模块/换任务/提精度"，不是"测误差的结构"。
3. **它便宜**——Day-0 证伪 0 GPU、30 分钟；全套 ≈ 1190 episodes ≈ 70 分钟。
