## 研究主张的证明义务

| 候选主张 | 所需证据 | 当前证据 | 必补项与风险 |
|---|---|---|---|
| 语义干扰导致合法任务性能下降 | 目标固定、长度/改写控制、颜色位置平衡后的配对新目标 SR | 仅 prompt metadata | token 长度/旧计划启动等竞争解释；Major |
| 语义效应依赖执行条件 | 分别施加 S/E，记录完整四格、时序和系统总效应；声明尺度与零模型 | 代数原型；未运行 VLA | 已有 Plus/PRO2.0 组合研究；非零不自动创新或认知因果；Critical |
| 交互结构有校准增量 | 同预算 generic residual/additive、时序修复，held-out 与消融 | 无真实校准收益 | 四格均值重参数化或模型容量差；Critical |
| 运行时可部署 | gate 只用当下 RGB/关节/历史；反馈年龄、内存/时延、饱和率实测 | 接口 smoke | 真值 condition_id、未来状态、人工看测试失败都不得用于部署方法；Critical |
| 正常能力保持 | 固定非劣效边界与配对单侧 CI | 无 VLA 数字 | “未显著变差”不等于非劣效；Major |
| 跨任务泛化 | 真正不同任务谓词、按 reset/轨迹组隔离的完整未见任务 | 两个标签实际为一种任务 | 当前生成器不能提供任务泛化证据；Critical |
| 同 SO-101 真机保持方法增量 | 同一合法目标/语义干扰/E、冻结参数、Raw/additive/完整方法配对 | 无真机 | 同型号/成功视频/排名一致均不足；Critical |
| 方法本身新颖 | 最接近原文的机制/信息/比较矩阵，区别不是换名字/本体 | 新近邻增加，未达门槛 | 过门槛前不扩大正式矩阵或撰写已成立贡献；Critical |

## 最小有解释力的对照集

| 对照 | 回答的问题 | 公平条件 |
|---|---|---|
| Raw | 原策略受扰基线 | 同 checkpoint、观测、reset 与时限 |
| 等长度无冲突旧计划/同义改写 | 是语义干扰还是 prompt 形式/长度 | 当前目标相同，平衡词序与对象 |
| 固定 global residual | 普通机械偏置是否足够 | 同动作边界与校准开发集 |
| semantic-only / execution-only | 单因子修复是否足够 | 同数据预算与可用输入 |
| additive | 联合收益是否需要交互结构 | 相同单项函数、门控与调参预算 |
| generic conditional residual | 结构优势是否只是容量/信息增加 | 相同参数量/输入/数据/更新次数 |
| matched-delay / queue repair | 收益是否来自更新鲜反馈 | 相同 wall-clock/动作频率/暂停规则；载体兼容时加 RTC |
| placebo / shuffled interaction | 方向是否有特异性 | 幅度与触发率匹配，开发集固定 |
| oracle | 尚有多少可恢复空间 | 明确使用额外真值，单列诊断上界 |
| CAG / BAS-VLA / IDR | 是否超出近邻推理校准 | 载体/动作/信息可匹配才复现；改写版标注适配 |

此表规定比较逻辑，不要求一开始把所有方法乘上所有任务。先检验能推翻核心假设的几项，再决定正式矩阵。
ACT/脚本可验证任务可解，但无语言 ACT 不能作为语言忠实性强基线。
传统视觉伺服若能用相同可观测输入实现，可排除低层追踪解释；使用物体真值的伺服只能列 oracle。

## 避免“交互”成为重命名

`I = y11-y10-y01+y00` 是标准 2×2 差分。若给四格各拟合一自由向量，完整模型只是四格均值的重参数化。
必须定义跨任务/状态共享的限制、可观测条件与预测对象，再用独立测试验证该结构的增量。
当前三向量校准原型没有自动获得“场”的连续性、可识别性、可迁移性或认知解释。

主终点可用风险差尺度的系统交互与方法成功率差；乘性/对数几率尺度可作预定敏感性分析，不能挑最显著的尺度。
不同尺度交互不同，地板/天花板也影响结果。报告每格成功/总数，并把行为、命令和实际运动分开。
依据：[交互报告原则](https://doi.org/10.1093/ije/dyr218)、
[Plus 组合分析](https://arxiv.org/html/2510.13626v3)、[PRO2.0 §4.4](https://arxiv.org/html/2610.24587v1)。

## 时间、数据与统计单位

- primary 配对键应是模型/任务/真实 reset block；scene ID 不代替物理状态。当前覆盖问题见 [协议审计](../../experiments/so101/PROTOCOL_AUDIT.md)。
- 分开记录训练初始化、环境抽样、推理采样和真机试验次序。冻结一个 checkpoint 的多次执行不支持跨训练随机性结论。
- 先对每 episode 形成预定统计量，再比较方法；不把帧、chunk 或重复同一布局当独立样本。
- 单格成功率给 Wilson 区间；方法差值按真实配对计算区间。独立配对二元结果可用预定 McNemar，
  有 reset/task 聚类时采用对应分块方案并说明假设。任务数很少时不声称对所有任务总体泛化。
- formal N 由 Pilot 的配对不一致率、最小重要差异与区间精度决定；先固定上限/停止规则，不能显著即停。
- 多重比较集合预先列出；已有 Holm 方案的原文复核仍待完成，不能仅引用不可访问条目假称已核验。

来源：[Wilson](https://doi.org/10.1080/01621459.1927.10502953)、
[McNemar](https://link.springer.com/article/10.1007/BF02295996)、
[Efron](https://doi.org/10.1214/aos/1176344552)、
[评估不确定性](https://arxiv.org/abs/2108.13264v4)。

## 停止/换方案条件

1. 最接近工作已覆盖同一中心机制，剩余仅换本体/基准/名字：停止把 ECCBF 当方法创新。
2. 交互由时序、状态支持差、饱和或目标改变充分解释，且无新增可部署结构：收缩结论或换问题。
3. held-out 上不优于同预算 residual/additive，或中性代价超过预定边界：不宣布方法成立，不继续用测试集调参。
4. 真机需重新拟合语义/交互参数才有效：不声称仿真校准迁移；若改成适配问题，应重新登记方案。

查新门槛和实证门槛分开：论文已覆盖可以不等 A100 就否决选题；新假设也可能被实验推翻。
