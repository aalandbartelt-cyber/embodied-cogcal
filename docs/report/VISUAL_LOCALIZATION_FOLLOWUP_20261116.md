# 视觉定位主线续审：有响应、响应不足，以及接触后的测量混杂

2026-11-16。沿用[选题复核](TOPIC_REVIEW_20261116.md)推荐的唯一主攻对象，
不增加新候选。本轮只读原始记录和相关工作，以正向运动学核算旧关节状态；
**未训练、未调用策略、未重置或步进物理、未新增 episode、未采购或预注册。**
以下是事后诊断，不改写原预注册或原始结果。

## 1. 这轮真正改变了什么

原先的“物体移开仍靠近旧源”确有记录，但**不能据此说策略没有利用位置信息**。
在既有 20 对 source-shift 记录中，首次预测 chunk 的抓取目标会沿物体平移方向
改变，只是幅度不足。闭爪时实测手爪的移动还混有命令与实测状态的差异及接触历史。

因此，本主线应围绕：

> **接触前的目标定位响应是否充分；如何区分策略规划不足与执行／接触造成的
> 位置变化，再用有针对性的示教校准检验解释。**

这是同一主攻问题的澄清，尚不是新机制成立、校准有效或查新通过。

## 2. 旧记录的独立几何复核

固定 XML SHA256 `d68b503cd3120456cd22bad710ec775ace7ad395b0daa02402d4ddc4227cae8a`，
MuJoCo 4.0.1，只调用 `mj_kinematics`。重构结果与已有遮挡实验记录的
**11,400 个 pinch-site 坐标完全一致**。分析状态时间始终为 0；没有物理回放。

比较量定义为

\[
g=\frac{(p_{shift}-p_{base})_{xy}^{T}\delta_{object}}
        {\|\delta_{object}\|^2},\qquad \delta_{object}=(0.02,0.02)\,m.
\]

它是这个固定对角位移下的有限差分投影，不是完整 Jacobian、内部注意力解释，
也不是控制器的已辨识闭环增益。`g=0.6` 不能单独读成“正确跟随了 60%”，还要看
横向偏离、时刻、目标运动和接触。

以下均取每条轨迹首次向下穿过夹爪**命令**阈值的事件，三个事后阈值全部报告。
每格都使用全部 20 对，不按成功与否挑样本。

| 夹爪阈值／rad | 首次 query 预测目标的 g 中位数 | 实际发送命令对应目标的 g 中位数 | 实测关节重构位置的 g 中位数 |
|---|---:|---:|---:|
| 0.18 | 0.200 | 0.241 | 0.556 |
| 0.20 | 0.197 | 0.262 | 0.611 |
| 0.22 | 0.185 | 0.287 | 0.622 |

“预测目标”是预测关节目标的 FK，**不意味着整段都被执行或物理可达**。
首次 query 的两条件初始 q 相同、图像不同；这段计划在未来接触发生前已被记录。
再把两条件统一到 baseline 的预测 index，g 中位数仍为 0.197、0.197、0.185，
所以这个小幅响应并非只由选择不同闭爪 index 造成。

原全程分别取最小距离的 anchoring index 也复算得到 19/20 为正。
它与上述非零空间响应同时成立，说明该指标只能描述靠近旧源的倾向，不能辨识
“完全不定位”或“视觉只作存在门控”。

## 3. 为什么不能把实测 g≈0.6 当成定位改善

在阈值 0.20rad 处，shift 组命令对应位置与实测位置的距离中位数为 **29.24mm**。
实测位置的横向投影系数中位数约 −0.75，而命令对应值约 −0.052；仅看平行方向
会漏掉明显的方向偏离。此时物体从初始位置的最大位移中位数已达 **17.06mm**。

逐物理步接触记录进一步表明：

| 条件 | 首次机器人接触时间：最小／中位／最大 |
|---|---|
| baseline | 1.6665／2.6613／2.7160s |
| shift | 1.5790／1.7503／1.8125s |

两组首个记录点均无机器人接触，故不是这批记录中“出生即碰撞”的证据。
但 shift 的全部 20 条在首次闭爪前已经接触，因此其后的位置既含视觉驱动的
策略反应，也含不同命令、跟踪误差、物体运动和后续观测。
**这些记录不能单独证明 29mm 差距全部由接触造成**，更不能据此提出新补偿器。

为检查接触前的情况，事后选择全部回合共同无机器人接触的 1.5s（control step44）：
实测位置与命令位置的 g 中位数分别为 **0.187、0.186**。它与首次 query 的小幅
空间响应相容，而非“完全零响应”。该时刻按已读接触时间选定，不当作事前终点。

因此，当前证据支持的是**小幅定位响应 + 后续接触／执行混杂**的描述。
具体原因仍可能包括窄示教分布、状态捷径、动作表示和执行时序；尚未排除这些
简单解释，也尚无该偏移布局下独立成功 teacher 的严格资格证据。

## 4. 新读的直接近邻，及与我们问题的区别

### What Matters, When?（2609.05376v1）

[原始全文](https://arxiv.org/pdf/2609.05376v1) 已研究 ACT 的阶段／视觉线索相关
目标与容器选择，比较干扰物增强、注意力约束和 appearance prompt，并指出
干扰不变性不足以保证任务空间几何得到保留。它有仿真和 UR3e 结果，不能只说
“已有分类学”而忽略这篇直接近邻。

其空间表示分析被作者明确限定为相关性分析；prompt 身份干预则针对选择哪个
目标。我们的当前检查针对一个目标的位置平移、计划／命令／实测三种位置及接触
前后时序。**这只是问题边界差别，尚未证明足以构成新贡献。** 泛称“图像影响
动作不等于正确 grounding”或“诊断后修正”不能作为本项目新原理。

[作者页面](https://vivekchavan.com/publications/) 列为 ECCV DexHAND 非归档扩展摘要、
扩展稿在审；本轮取得的 PDF 与元数据在页数／稿件说明上有差异，版本与 hash
按实际下载保留，不将其写成已接收期刊论文。作者项目页为
[robotics-imitation-learning](https://robotics-imitation-learning.github.io/)。

### Causal-ACT（2507.22380v1）

[原文 §3、§5–7](https://arxiv.org/pdf/2507.22380v1) 研究 ALOHA cube transfer 中
移除干扰物后的域变化，以图像 embedding 二值 mask、联合训练和有 reward 的
执行搜索选 mask。它是必须考虑的强近邻，而不是“换 SO-101 就不同”。

本轮实际检索到[作者 GitHub](https://github.com/yfchenShirley/Causal_ACT_code/tree/6db171cbbe1d199a3daca64540a8a865b4e89cf7)，
固定 revision 读取 README、policy 和 DETR-VAE 的相关部分：embedding 乘 mask，
保留 qpos；README 与论文匿名代码入口逐字节一致。源码包含 14D ALOHA 设定，
不是可直接控制 SO-101 的预训练权重。未安装、运行或复现其性能。

### 既有 State-free 与空间覆盖研究

[State-free](https://arxiv.org/pdf/2509.18644) 已研究去状态输入、相对 EEF 动作与充分
视觉观测；[Indy7 空间覆盖研究](https://github.com/SIRLab-RobotArm/indy7-act-spatial-coverage/tree/69c0fd61b3e1885bb485efb532152c027a501429)
已比较相同示教数量下的位置覆盖。两者继续作为强对照，不能将其已研究的修正
直接改名。当前固定 ACT 在未见位置上的失败，不自动证明它们解决不了。

## 5. 对选题状态的影响

主攻方向保持收敛，不恢复 ECCBF／TPSC／通用 actuator 或接口补偿，不扩大候选。
现有数据已经把待解释现象从“零定位”改为**接触前目标定位欠响应**，并发现接触
后的手爪足迹不能直接当作纯视觉定位响应。

可能值得争取的具体贡献，是**能区分计划、命令与接触后实现的定位诊断，并据此
给出有解释、超出普通位置扩增的示教校准证据**。当前还没有那项独立增量的验证，
不能承诺新颖性、校准收益或 SCI 分区。已有分析是同一 checkpoint、任务和固定
位移的一次事后核算，重复 FK 不增加样本量。
