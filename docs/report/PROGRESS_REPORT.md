# 给导师的研究进展汇报准备稿

用途：约 10–15 分钟组会/选题讨论的逐页提纲，当前不生成假结果图。日期：2026-11-14。
报告题目建议：**低成本机械臂上的 VLA 失效诊断与修复：研究现状、平台准备及选题筛选**。
具体方法尚未定型，标题不宣称 ECCBF 已成立。

## 1. 本次汇报的决定

- 已有 SO-101 仿真与数据工具，正在完成策略部署前准备。
- 公式级深审后，停止当前 ECCBF；两个宽泛替代方案也未通过核心创新门槛。
- 请讨论核心科学问题与可证伪增量，而非先把工程流程包装成贡献。

讲述：目前汇报的是准备进展与选题风险。已有工程工作可以复用；如果机制被前作覆盖，就换问题。
依据：[路线决策](../prior-art/ROUTE_DECISION.md)。

## 2. 研究对象与实际场景

- 用户指令、RGB 与关节观测输入 VLA，动作通过真实控制器/队列执行。
- 常见错误可能来自目标理解、状态感知、执行时序或机械追踪，修法并不相同。
- 真机验证要检验同一个核心对比，使用同型号 SO-101 与对应任务。

讲述：单看任务失败不能判断哪一层出问题；选择方法前应先明确可观察信息和评价目标。
来源：[CorrectVLA](https://arxiv.org/html/2608.29967v2)、[Sentinel](https://arxiv.org/html/2410.04640v2)。

## 3. 已有基础：开放策略与低成本硬件

- OpenVLA/OFT 可作为标准辅助载体；SmolVLA 是 SO-101 主线候选。
- 低成本硬件不等于已有通用 checkpoint 能直接执行当前任务。
- 本项目的 LIBERO 7D Cartesian 动作与 SO-101 六关节 rad target 存在接口边界。

讲述：A100 解决模型计算，不能替代本体、相机、动作统计与数据适配。
来源：[OpenVLA 正式版](https://proceedings.mlr.press/v270/kim25c.html)、[SmolVLA](https://arxiv.org/abs/2506.01844v1)。

## 4. 研究现状一：语言忠实性

- ICBench/IGAR：矛盾指令下防止执行旧任务。
- LIBERO-CF/CAG：同场景可行替代任务及动作引导。
- SwitchVLA：任务执行中根据接触/状态切换意图。

讲述：无解指令下正确停止、完成可行新目标和执行中切换是三个评价问题，不能混成一个成功率。
来源：[IGAR](https://arxiv.org/html/2603.06001v2)、[CAG](https://arxiv.org/html/2602.17659v3)、[SwitchVLA](https://arxiv.org/html/2506.03574v1)。

## 5. 研究现状二：组合扰动不是空白

- Plus 已研究两两扰动组合；PRO2.0 包含运行时执行/语言和多阶组合。
- VLA-Gauge 还把诊断与针对性改进连接起来。
- 标准四格差可以是测量工具，公式本身不作为创新。

讲述：我们需要回答某种结构是否有新预测和方法增量，不能只再次展示两个扰动一起更难。
来源：[Plus](https://arxiv.org/html/2510.13626v3)、[PRO2.0](https://arxiv.org/html/2610.24587v1)、[VLA-Gauge](https://arxiv.org/abs/2610.16567v1)。

## 6. 研究现状三：推理修正与门控残差已有近邻

- BAS-VLA：匹配任务语义变化与选择性校准。
- IDR：反事实模态输入、动态作用估计及门控残差。
- RTC/SmolVLA：执行时序自身也能改变表现。

讲述：只优于 Raw 无法说明有新机制；需要同信息、数据、参数和延迟预算的残差/调度对照。
来源：[BAS-VLA](https://arxiv.org/html/2609.23650v2)、[IDR](https://arxiv.org/html/2607.25516v1)、[RTC](https://arxiv.org/abs/2506.07339v2)。

## 7. 本项目已经做到什么

- 官方固定版本 SO-101 模型、MuJoCo 场景、reset、RGB/关节观测和六关节动作接口。
- 基础几何放置判定、视频和逐步日志；数据合并/统计避免 step 充当 episode。
- 本地分析 148 项通过（9 个可选物理测试跳过），独立仿真 16 项通过；云端独立仿真也通过。

建议画面：[本项目实际场景截图](../../results/figures/so101_readiness.png)。
讲述：以上证明工程接口可跑，不证明 VLA 自主抓取或算法提升。
证据：[LOCAL_VALIDATION](../../experiments/so101/LOCAL_VALIDATION.md)。

## 8. 本轮发现的协议问题

- 实际生成 100 场景 / 400 四格 metadata，仅有 8 组物理布局、16 组布局—目标组合。
- 两个 task_id 归一颜色后只对应一种抓取放置模板，不能声称跨任务。
- 当前 S 是作废计划文本干扰；0/3 步延迟仅写入 metadata，未施加到模型 rollout。

讲述：正式采样前先解决实际任务、覆盖和因子执行。多生成 ID 不等于增加独立证据。
证据：[协议审计](../../experiments/so101/PROTOCOL_AUDIT.md)。

## 9. 深审裁决与换题探索

| 候选 | 决定性证据 | 裁决 |
|---|---|---|
| A：原 ECCBF | 普通条件残差等价；400/400提示可精确清理；IMPACT-VLA闭环交互归因 | 停止当前核心主张 |
| B：迁移可信性 | 差值PPI、选择性AIPW、预测辅助最佳方案识别已有解法 | 停止宽泛新方法 |
| C：主动辨识 | 决策论排障、经典主动诊断、Fly-by-Code物理探针 | 停止宽泛新方法 |
| 接触补偿 | 接触估计/调制、training-signal hedging已有近邻 | 不直接选为新方法 |

讲述：撤回初轮C/B推荐。拟限时检验接触反馈是否污染持久在线更新，先与冻结/重置/传统适配比较；
这是探索问题，尚无通过查新的新机制。结构审计是数学/文本检查，没有运行VLA。
来源与否决规则：[路线决策](../prior-art/ROUTE_DECISION.md)。

## 10. A100 第一阶段只做什么

1. 环境前检、权重加载、标准 baseline 与视频。
2. SO-101 策略动作/相机/normalizer 接口和任务可解性。
3. 相同输入预测不变性、语言正对照及原始时序日志。
4. 科学协议与查新门槛通过后，才运行最小机制 Pilot。

讲述：先把载体跑通，同时冻结一个可否证问题；不先承诺大规模训练或正式成功率。
操作入口：[NEXT_A100](../NEXT_A100.md)。

## 11. 真机投入怎样产生论文证据

- 同任务谓词、观测/动作含义、干扰注入位置、时限与失败分类。
- 若接触探索成立，真机检验同一个“暴露反馈进入更新→后续任务表现”的对比；不再绑定已停止的A/B/C方法。
- 参数冻结、布局测量和试验顺序登记；单独记录仿真—真机差和绝对成本。

讲述：真机用来推翻或支持同一命题。SO-101 Bench 的结果说明平台有参考价值，也提醒仿真可能偏乐观。
来源：[SO-101 Bench](https://arxiv.org/html/2610.36420v1)。

- 选题：与最接近原文逐项比较，通过 G1–G3 才冻结。
- 工程：A100 模型/接口/日志 smoke；真实任务和独立 reset manifest。
- 科学：预登记最强简单对照、主终点、区间和停止/换题条件。
- 论文：文献已可导入，相关工作有初稿；效果表全部等待真实数据。

讲述：本阶段目标是获得可信的“继续或换题”依据，不把未知结果预先写成成果。

## 预计问答

| 老师可能问 | 当前如实回答 |
|---|---|
| 创新点确定了吗？ | 没有。旧核心和两个宽泛备选均被否决；目前冻结的是淘汰依据和有限探索规则。 |
| 为什么不直接用现有校准方法？ | 应先把现有方法做成可比基线；新方法必须证明同预算增量，否则没有理由另造一个。 |
| 闭环算创新吗？ | 不能。流程是组织方式，中心贡献必须是一条新机制、可识别条件或新决策方法。 |
| Google Scholar 查了吗？ | 已直接尝试但不可访问；有逐题名入口和替代原始来源核验，没有伪造 Scholar 结果。 |
| 真机现在能买吗？ | 可先核 BOM 和接口；具体任务/载体确定后按共享实验需要采购，不先承诺价格或报销。 |
| 当前成功率是多少？ | 没有本项目 VLA 成功率。脚本 smoke、测试通过和 metadata 数量都不能替代它。 |
| 如果探索无效或简单方法已解决呢？ | 停止该题，不把经典方法换名字当创新；小样本区间宽则报告不确定。 |
| 为什么还用 A100？ | 已选 A100 做模型运行，独立环境和可记录的资源条件有助复现；论文质量取决于设计和证据。 |
