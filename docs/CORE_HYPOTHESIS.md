# ECCBF：核心假设与声称边界

**2026-11-14 深审裁决：停止当前 ECCBF 核心创新主张。**
当前三向量校准与普通条件残差等价，生成器有精确文本清理基线；反事实闭环交互也有直接近邻。
以 [路线裁决](prior-art/ROUTE_DECISION.md) 为准；以下保留历史设计，不作为当前待启动的主实验。

## 被停止的历史假设

旧路线曾拟检验以下命题；当前实现未获得相对普通残差的新结构，不能仅以命题可证伪就称为创新：

> VLA 的语言—观测冲突偏差会随机器人本体和执行条件改变；这种具身条件化交互项可以被
> 匹配反事实任务识别，并被用于提高受扰任务成功率。

当前生成器的 S 实际是“作废计划文本干扰”，合法当前目标不变；它不等同无解语言—场景矛盾或执行中改指令。
正式 S、任务和独立场景覆盖尚待修订，见 [协议审计](../experiments/so101/PROTOCOL_AUDIT.md)。

工作名：**Embodiment-Conditioned Cognitive Bias Field（ECCBF，具身条件化认知偏差场）**。

## 因子定义

每个场景使用相同初始状态和随机种子，构造语义条件 `S` 与执行条件 `E` 的 2×2 组合：

| 条件 | 语义 | 执行 |
|---|---|---|
| `(0, 0)` | 中性 | 标准 |
| `(1, 0)` | 语言—观测冲突 | 标准 |
| `(0, 1)` | 中性 | 延迟/外参/执行扰动 |
| `(1, 1)` | 语言—观测冲突 | 延迟/外参/执行扰动 |

设四个条件的平均动作向量为 `a00, a10, a01, a11`：

```text
b_sem = a10 - a00
b_exec = a01 - a00
b_int = a11 - a10 - a01 + a00
```

旧设计将 `b_int` 作为机制量。它本身是标准四格交互对比，不支持新机制；旧设计拟用它解释为什么
某类校准在具身条件变化后有效或失效。

上述 raw action 四格差是行为对比，尚不等于认知偏差。若 S 合法改变了目标，动作差
可能是正确响应，不应直接减回中性动作。部署校准需基于各语义条件合法参考的残差，
详见 [实验效度](EXPERIMENT_VALIDITY.md)。纯物理变化且策略输入相同的首步预测应不变。
原型代码通过代数测试，不代表交互或准确率收益已经成立。

## 历史拟注册假设（未执行注册）

- H1：冲突条件相对中性条件会产生可重复的任务成功率下降或动作偏移。
- H2：`b_int` 在至少一个未见任务上不为零，并且方向具有稳定性。
- H3：ECCBF 校准相对 Raw、语义单独校准、执行单独校准和无交互项加法校准，能提高冲突
  条件的任务成功率。
- H4：ECCBF 在中性条件下的性能下降不超过 5 个百分点。
- H5：仿真中识别的语义校准方向在真实 SO-101 上保持一致；本体变换允许重新估计，
  语义校准参数不在测试集上重新拟合。

## 不使用的表述

- 不把“测量—建模—补偿—验证”本身写成创新点；它是实验组织方式。
- 不把 WYSIATI 或锚定效应单独写成新发现；相近的语言—视觉冲突已经有 ICBench、
  LIBERO-CF 等工作覆盖。
- 不声称解决所有 VLA 鲁棒性、工业精度或通用 sim-to-real。
- 在查新矩阵完成前不使用“首次”“填补空白”等绝对化表述。
