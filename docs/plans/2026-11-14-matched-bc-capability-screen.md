# 匹配任务的小BC能力screen

本实验承接用户已授权的“SmolVLA/BC先检验能力，再判断机制”，不实现新方法。
目标仍是选出可查新、有先进性且同题仿真—真机的研究方向；本screen只移除载体混淆。

选择：先用小型RGB+q历史的chunk BC，确认当前物理任务可学习，再考虑SmolVLA扩展。
直接再训练公开单任务SmolVLA仍有相机/单位/场景混淆；只用特权物体状态的MLP则不能验证用户要求的输入。

1. 外部SO101 teacher固定b02b8b2，官方项目XML与TPSC原20条不改。独立资格目录。
2. 先检查低频30Hz零阶保持的teacher能抓放。先前10/10使用2000Hz变化命令，不能直接当30Hz示范合格。
3. 固定单一任务：source近[.2,-.075,.014]m，goal[.2,.075,.014]m。两目标资格试验的55mm圆互相重叠，
   只证明运动可行，不是语义左右任务；本screen不以它估计语义能力。
4. 所有split以episode seed分离，24train/8val/20test；source在±5mm方形内变化。
   goal固定，单一语言任务不声称语言理解。RGB+实测q历史为策略输入；物体真值只可用于teacher/evaluator。
5. 每episode285个30Hz命令，实际写入后计数。显式rad、相机、renderer/模型hash、
   无姿态传送/绑定；以抬升、双指接触、放桌、释放和35mm目标误差联合验收。
6. 小BC固定seed42、2000更新、最终checkpoint；无best-checkpoint或test调参。保存chunk/q/裁剪/失败。
   若基线少于16/20成功，机制不作解释；这是实用能力门槛，不是新方法效果或统计功效保证。
7. 能力合格后才做补偿机制screen：同一冻结策略、同初态，分别改变执行与仅观测做诊断。
   与普通gain mismatch、NADA、噪声滤波、接触力/时序变化比较。没有实测证据前不命名新算法。

停止条件：teacher低频不合格则先定位，不训练；新方向被近邻直接覆盖则停止该核心主张。
大图像数组/权重留data/checkpoints忽略目录，提交生成/训练/评估脚本、小记录和哈希。

## 训练前的资源调整

首条全30Hz图像示范物理成功，但用时183.50s；实测EGL为Mesa llvmpipe而非CUDA渲染。
该运行主动停止且保留首条数据/中断记录，不复用进后续数据。
新采集目录使用5Hz双相机、30Hz控制、每6控制步重规划；每条记录图像年龄，训练/评估时序一致。
仅渲染关闭阴影/反射/雾以节省CPU，物理/任务/成功标准不变。重新核验teacher后才采集。
