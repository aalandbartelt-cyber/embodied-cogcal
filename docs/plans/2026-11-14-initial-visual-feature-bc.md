# 固定初始视觉特征的普通BC资格对照

这是看到carry11/20、reset4/20之后的自适应载体调整，不是预注册新机制/新方法研究。
8条carry抬升失败均在首个gripper command≤.2rad前发生>2mm物体XY位移。
这排除了“只增加记忆就足够”的工程预期，但未识别视觉、动作预测与接触的具体因果。
训练24/验证8初始RGB的单一橙色mask+线性回归诊断平均val位置误差1.49mm；
它仅表明初始RGB有定位信号，不证明原CNN忽略该信号。

本次只再做一个明确、常规的视觉特征基线，不进行结构/阈值搜索：

1. 完全保留原物理载体、5Hz查询/30Hz控制、285控制预算和严格完整成功条件。
2. 复用同32条示范与hash、原train-only q/action统计；全48查询训练。
3. 在原普通carry GRU输入中加入初始双RGB得到的6个固定颜色特征（每视图cx/cy/面积）。
   使用上一只读诊断的同一mask，不调阈值。特征只在episode开始从RGB计算并缓存，
   各自标准化仅用24条train的初始特征；不传入物体/目标真值或episode时间。
4. 保留原CNN、q局部历史和GRU；仅投影层输入多6维。
   这改变了表示与少量参数，不能作为纯粹“初始记忆”效应的因果消融。
   固定seed42、Adam .001、batch8完整episode、2000更新及最终checkpoint；不挑best。
5. 用全新8100–8119测试20条；不挑原成功seed或放宽条件。至少16/20才可建立窄任务能力。
6. 这只能作为固定颜色/相机/初态范围内的ordinary BC，不能声称通用VLA、语言理解或新方法。
   初始关键帧缓存、颜色特征和循环策略都是既有工具，不列为创新。
7. 保存所有结果；若仍不合格，停止继续微调此小模型架构，重新评估数据/视觉分辨率/成熟策略载体。

未来机制实验使用新冻结条件与样本。本次即使通过，也未证明“改善精度会损伤策略”，
该问题仍须查新与独立因果实验，不把资格成功率当论文结果。
