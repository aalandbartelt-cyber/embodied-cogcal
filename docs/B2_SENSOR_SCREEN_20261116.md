## 1. 先确定科学问题需要哪一种物理量

| 量测路线 | 能直接提供什么 | 仍缺什么 | 同题仿真—真机的要求 |
|---|---|---|---|
| 单轴力敏/应变测量，装在指尖或工具载荷路径上 | 一个方向的电信号；经装配后校准才能解释为该方向的力 | 切向力、力矩、接触位置；电阻式读数还受接触面积/加载历史影响 | 分别定义每个传感器的载荷路径、方向、零点、量程、采样与延迟。指尖法向合力可与对应接触区的 normal-force sum 对齐，不能把双指总和混作单指力 |
| 三轴力或六轴力/力矩 | 传感坐标系下的向量力/力矩 | 没有天然的接触分布；安装偏置、重力和运动载荷仍须区分 | MuJoCo 的 `force` 是子体与父体间的三维相互作用力，不是某个接触点的纯外力；需匹配真实安装位置/坐标系及载荷补偿。六维量还需对应 torque 通道 |
| 空间触觉（光学、磁式、阵列） | 图像/磁场/阵列电信号，以及校准后可能得到的形变、局部接触或力特征 | 原始输出不自动等于 N、Pa、滑移或任务进展；更换表皮也改变接触材料 | 需要相应传感机理与材料模型。原生接触几何不等于真实相机图像或磁场；不能用仿真特权量冒充硬件观测 |

**决定传感路线的是需要区分的物理状态。** 研究若只需法向合力，可先审查标量力
路线；若假设依赖剪切、接触位置或形变分布，就必须证明所选硬件能测到，不能用
一个标量替代。当前预算未知，尚不能据此选定具体型号或总成本。

官方 [MuJoCo sensor 文档](https://mujoco.readthedocs.io/en/stable/XMLreference.html#sensor)
明确区分：`touch` 输出接触区法向力之和；`force` 输出体间三维力；`tactile`
输出 taxel 的穿透深度与切向滑动速度，弹性体耦合需用户后处理。
因此，**不能直接把 `tactile` 的深度输出称为压力/力真值**。
本轮只核到本机 MuJoCo 4.0.1 的发行元数据，没有实例化或验收新传感器；
当前在线文档也不作为本地新场景已可运行的证据。

## 2. 原文已经排除哪些宽题

### 2.1 传感信息与材料被动效果的拆分，已有直接工作

[TacO v2](https://arxiv.org/pdf/2605.21976v2)（2026-10-29）§IV–VI 比较六种触觉传感器。
同一硬件上训练有/无触觉输入的策略；跨传感器再比较无触觉策略，以分析材料、摩擦
和形态的影响。§VI-C 还测了重复性和读数漂移。

因此，“加触觉提高成功率”“传感表皮的摩擦/顺应性也影响结果”以及上述基本对照
不能作为本项目的新核心。这些对照仍是后续实验必须保留的有效性条件。
TacO 的漂移/重复性结果也不能直接迁移为本项目所选传感器的漂移规律。

### 2.2 换皮、替换实例后的策略迁移，已有直接工作

[AnySkin v3](https://arxiv.org/pdf/2409.08276v3)（2024-09-27）§III–V 使用磁式可替换
表皮，研究制造一致性、滑移检测，以及三个操作任务中的跨表皮实例迁移。
作者[项目页](https://any-skin.github.io/)链接到
[官方仓库](https://github.com/raunaqbhirangi/anyskin)。

因此，“低成本”“可换皮”“跨传感器实例泛化”这些表述本身不构成新题。
本轮没有构建该硬件，也没有确认其完整制造/采集成本符合用户预算。

### 2.3 力反馈、漂移补偿均有经典和近期基线

既有[接触适配审查](prior-art/deep-audit-contact-adaptation.md)已读过外层顺应控制、
位置控制器的外力估计、力/位置分工、残差控制、anti-windup 与接触条件适配近邻。
增加传感器后，这些对照仍适用；不能把接触门控或法向/切向分解重新命名为创新。

本轮取得 [Automated Continuous Force-Torque Sensor Bias Estimation v1](https://arxiv.org/pdf/2403.01068v1)
全文，重点读 §3 Eq.(31)–(55)：以已知末端负载惯性参数和运动学建立测量关系，
用 Kalman filter 估计 bias 及其漂移。因此“在线估计力传感零偏/漂移”也不是空白。

## 4. 待核问题的最低可辨识要求

下面是简化测量模型的必要条件分析，不是新定理，也不是本项目的实验发现。
若只有 `y(t)=F(t)+b(t)`，真实接触力与偏置都未知，则任意 `c(t)` 下，
`F'=F+c`、`b'=b-c` 给出完全相同的读数。仅对同一读数换网络/滤波器，
不会自动获得区分两者的信息。

2024 bias-estimation 稿的 Eq.(38) 使用 `W+b=Dθ` 和已知负载参数。
**由该模型推断：** 若出现未建模外部接触力，不能直接把全部残差都解释为 bias。
这不是在声称原论文已经评估并失败于本项目的接触条件。

任何后续候选至少要明确一种有效的附加信息或经过验证的先验，例如真实无载窗口、
独立参考量、受限的温度/漂移模型或可验证的物理约束。增加一个传感输入不自动打破
上述等价；参考通道本身也已有传统方法，仍需核对增量。

若简单基线足够，或观测条件下根本不可辨识，就停止该方法主张。
不能将“接触时冻结校准”本身作为贡献，不能用仿真已知 bias 作为真机策略输入。
