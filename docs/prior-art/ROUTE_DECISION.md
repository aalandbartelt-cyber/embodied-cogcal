# 查新门槛与换方案决策

更新：2026-11-14。用户明确要求：**查新不通过，应换方案**。本文件替代旧记录中对 ECCBF 组合贡献的乐观解读。
本轮使用 brainstorming 比较候选问题；这里只作研究筛选，不表示新方法已获验证或已经替换实现。

## 当前决定

**不冻结 ECCBF 为论文核心创新，不启动围绕旧主张的大规模正式矩阵。**
保留 SO-101/MuJoCo、数据与日志工具作为共用实验资产；A100 的环境/载体冒烟仍有价值。
现有证据足以否决“语言冲突 + 门控残差 + 扰动组合 + 同体真机”本身是新贡献的宽泛说法；
还不足以判定所有更具体的新机制都已被做完，也不足以宣布一个备选方向已查新通过。

## 为什么要暂停旧主张

| 已有工作 | 与当前主张重叠的原始证据 | 后果 |
|---|---|---|
| [CAG](https://arxiv.org/html/2602.17659v3) §4–7 | 可行反事实、冻结策略动作引导、真机 | 反事实纠偏不是新问题 |
| [BAS-VLA](https://arxiv.org/html/2609.23650v2) §3–5 | 匹配语义改变、残差、证据门控 | 门控残差不是核心增量 |
| [IDR](https://arxiv.org/html/2607.25516v1) §IV | 视觉/本体感知反事实推理、动态作用估计、门控残差 | 反事实诊断后修动作的流程也已有直接近邻 |
| [Plus](https://arxiv.org/html/2510.13626v3) §5/附录 F | 两两扰动组合分析 | “发现交互”不能独占 |
| [PRO2.0](https://arxiv.org/html/2610.24587v1) §4.4/附录 C | 执行/语言运行时干预与组合 | 不能把执行因子视为未研究维度 |
| [VLA-Gauge](https://arxiv.org/html/2610.16567v1) §III–V | 组合扰动、诊断后针对性改进 | “诊断—改进闭环”不是独立贡献 |
| [SO-101 Bench](https://arxiv.org/html/2610.36420v1) §3–5 | 同体数字孪生/真机评估 | 换 SO-101 不能自动补足方法创新 |

这些重叠不是“找一篇完全同名论文”才算重复。若中心问题、可用信息、关键机制和证明对象已覆盖，
更换平台、任务名或把标准交互公式换符号仍不能通过科学贡献门槛。

## 三个候选问题的比较

### A. 收紧原问题：交互结构是否带来可预测的校准增量

问题：在当前合法目标固定、反馈时序清楚时，一个跨任务共享的交互结构是否以同样的数据/参数量，
优于无结构 conditional residual 和纯调度修复？

- 优点：最能复用旧设计；可先在仿真进行低成本否证。
- 主要风险：BAS-VLA、IDR、CAG、PRO2.0 已覆盖大量组件；标准四格差和自由四格偏置不构成新结构。
- 唯一可继续的理由：给出明确结构限制及新预测，并在未见任务/强度上证明增量。
- 否决条件：只能换名/换平台，或普通 residual/时序对照吸收收益。
- 当前评级：**高风险，保留作小范围诊断候选，不作为默认论文创新。**

### B. 换问题：仿真能否可信预测“校准带来的增益”

问题：相比只预测原策略的绝对成功率/排名，如何用有限真机配对试验判断某个修复在现实中是否真有增益，
并在模拟器不可靠时拒绝作迁移结论？研究对象是方法差值的可信估计与选择决策。

- 近邻：[SIMPLER](https://proceedings.mlr.press/v270/li25c.html) 已研究排名/性能相关性；
  [MetaFine §8](https://arxiv.org/html/2605.19986v1) 已将 prediction-powered inference 用于少量真机加大量仿真。
- 优点：真机直接检验核心结论，符合低成本、小样本与同体要求；可以复用多种校准作为干预候选。
- 风险：把标准 PPI 用到两个方法相减，或仅改成 SO-101，不足以成为新方法；配对匹配误差/自适应选择必须有实际新处理。
- 首个可否证试验：多模拟器参数设置下，绝对 SR/排名较好是否仍会误判修复差值符号；不能预设一定发生。
- 否决条件：现有 PPI/直接配对区间即可同预算解决，且没有新的识别/选择问题。
- 当前评级：**值得定向查新，尚未过门槛；真机前只能做模拟失配压力测试。**

### C. 换问题：主动辨识“看起来一样、修法不同”的失败

问题：当被动 RGB/关节/动作历史不能区分两种失败原因时，能否选择一个低成本、受约束的探测动作，
在共享的仿真/真实 SO-101 任务中获得足以选择修复的信息？核心是可辨识条件与探针选择，而不是泛化失败分类。

- 近邻：[Which Hand Was Late? §4.3/§7](https://arxiv.org/html/2610.37533v1) 显示被动不可辨识并使用升级式修复；
  [RoboMD](https://arxiv.org/abs/2412.02818) 已主动搜索失败条件；
  [FIERL](https://arxiv.org/abs/2405.04938) 已研究主动故障辨识输入。
- 优点：可以构造有明确真值的故障注入和反例；真机验证的就是探针信息与修复决策，不是附加演示。
- 风险：主动诊断是经典控制问题，单纯加信息增益/一个动作/一个 VLM 不够；需证明新任务中的可辨识边界与同预算恢复增量。
- 最小可否证试验：先在仿真构造两类确实难由被动观测区分且所需修复不同的故障；
  若已有传感器/时间戳已经能区分，或固定重试/两种修复全上即可同成本解决，就淘汰该任务。
- 硬件要求：先限制 RGB、关节编码器与命令时序；不默认购买力矩/触觉传感器或双臂。
- 当前评级：**建议优先进一步查新的备选；目前没有宣称新颖性成立。**

## 选择建议

优先补查 C，其次 B；A 只保留为能快速否证的研究候选。理由是 C 更容易把“必须识别什么、为什么被动信息不够、
探测后决策如何改变”说成一个核心命题，且能把真机直接放在命题验证上。
这项排序是基于本轮原文的研究判断，不是文献证明的优越性或录用预测。

不建议直接转成“更快的异步 VLA / 缓存语义校准”：
[RTC](https://arxiv.org/html/2506.07339v2)、[DEFLECT](https://arxiv.org/abs/2605.19294v3)、
[Leap-VLA](https://arxiv.org/abs/2611.01011v1) 已显示该方向有直接近邻，换过去仍须面对核心重叠。

## 硬门槛与下一轮产物

| 门槛 | 通过依据 | 不通过时 |
|---|---|---|
| G0 事实可查 | 原始题名/作者/版本、正文机制、公开范围可核 | 不使用该引用作贡献判断 |
| G1 核心差异 | 与最接近工作逐项比较输入、机制、估计对象、泛化与预算 | 同核心仅平台不同，淘汰候选 |
| G2 可证伪/可负结果 | 一个能区分本方法与最强简单替代的实验 | 只能展示流程/视频，重建问题 |
| G3 小预算可实现 | 单卡仿真、现有本体可观测量、同协议真机 | 需要未经确认设备/大模型训练，缩小或换题 |
| G4 实证增量 | 按预登记独立测试得到增量与合理区间 | 无增量，停方法强主张，不事后挑任务/指标 |
