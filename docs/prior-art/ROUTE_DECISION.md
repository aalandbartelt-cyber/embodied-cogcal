# 研究方向裁决：停止旧核心，先验证新的问题是否成立

日期：2026-11-14；第二轮独立深审后的决定。用户要求核心科学增量、多对照组、先仿真，
真机必须检验同一个命题。不能用“闭环”、低成本平台或组件组合充当创新。

**用户确认的换题约束（2026-11-14）：**保留低成本 SO-101、A100、同体仿真—真机；
核心研究问题可以更换。后续检索不要求延续 ECCBF、认知偏差、语言冲突或校准主题。
硬件/算力是可实现性条件，不能作为新颖性来源。接触适配探索仍是可淘汰候选，不因这次确认而被选定。

**当前候选更新（持续查新中）：**风险来源分解已被 PATCH/CommitFlow/ReTrace 等近作压缩；
新增首要候选是 [动态可执行策略规范与同体等价证书](discovery-direction-20261114.md) 和其
[公式级深审](deep-audit-executable-spec.md)。它比接触适配更贴合工业精度补偿和 SO-101 真机，
但尚未通过查新，必须先与 Same Weights、FAN、TeAR、PolicyIK、经典系统辨识/DOB 对照。

**决定：停止将当前 ECCBF 作为论文核心方法；撤回初轮“优先 C、其次 B”的推荐。**
三个宽泛候选的核心机制都已有直接解法。目前没有一条替代方法通过我们的选题门槛。
这不表示整个机器人领域没有研究空间，而是不能继续靠修改名称冻结当前方案。

下文 A/B/C 是本轮候选编号，**A 对应用户此前称为“B 路线”的 ECCBF**；
本表 B 专指后来提出的“修复增益迁移估计”，不能混为同一路线。

## 2. A：当前公式与实验不足以支持新结构

设四格均值为 m00、m10、m01、m11，当前实现使用

~~~text
βS = m10 − m00
βE = m01 − m00
βSE = m11 − m10 − m01 + m00
r(s,e) = u βS + v βE + uv βSE
~~~

u、v 是阈值门控后的分数。二元角点有 r(s,e)=mse−m00；连续分数是同一四格表的双线性插值。
这就是以 [u,v,uv] 为特征的普通条件残差重参数化，没有额外跨任务结构或动态辨识机制。
只比较 additive，会把额外交互自由度的收益误当新结构的收益。

当前生成器还把“上一计划已作废”放在完整的 Current task 字段前。
只保留该显式字段即可恢复配对中性指令，无需 evaluator 或隐藏目标。
**实际结构审计：100 场景的400条记录全部恢复为配对中性文本；四角点与1,000组连续分数满足上述恒等式，
最大数值误差小于1e−12。** 证据：[脚本](../../scripts/audit_eccbf_structure.py)、
[原始输出](../../experiments/so101/novelty-structural-audit.json)。
随机向量只作代数验证，**不是 VLA 轨迹、物理实验或成功率**。

在相同初态、调度、缓存与随机流下，相等输入应产生同分布的整个闭环轨迹；
这是逻辑推论，尚未运行策略验证。它不修复执行扰动，也不适用于任意自然语言，
但足以要求当前协议先比较这个简单基线。

[IMPACT-VLA §III-C/D](https://arxiv.org/html/2609.15005v1) 已从相同初态重跑反事实闭环，
并以四点差研究交互。它做归因而非部署动作修复；IDR 的输入模态干预也不等同外部执行扰动。
这些范围差异应保留，但“加一个校准器/换 SO-101”尚不能形成核心增量。

## 3. B/C：为何不能直接改成它们

### B：差值不是新的统计对象

真实配对差值 D=Yrepair−Ybase，仿真差值 F=frepair−fbase，直接使用

~~~text
Δhat = mean(F, 大仿真集) + mean(D−F, 小真机集)
~~~

就是 PPI 均值估计。PPI++ 处理权重，AIPW 处理已知采样概率下的选择性审核，
预测辅助 best-arm identification 已处理有偏代理、差值残差协方差、预算配置和置信停止。

**纠正初轮说法：SIMPLER 已研究相对性能和改进信号，并非只预测绝对成功率。**
MetaFine §8 也已有机器人少量实机配对加大量仿真的 PPI 实例。
2601.21471 的 v1 全文题名为 *Best Arm Identification with LLM Judges and Limited Human Audits*，
v2 已改为 *Designing Service Systems from Textual Evidence*，不混用版本。
前者 abs 页还漏了最后一个词；补充元数据保存此异常及原始全文题名出处。
具体估计式、适用条件和不适用边界见 [B 深审](deep-audit-transfer-effects.md)。

### C：按修复收益选探针也已有经典母题

Breese–Heckerman 1996 已按观察/实验后的期望总修复成本选择动作；
把信息增益换成修复价值不是新原理。
[Fly-by-Code §3/附录 D.2](https://arxiv.org/html/2610.12549v1) 更已用物理试探检验被动日志未解决的失败原因。
其诊断发生在仿真，实机执行改好的程序；这不同于实时真机 probing，但只扩展验证范围仍不足以成为核心创新。

若“同时尝试全部修复”或廉价升级已解决问题，识别所有真实原因可能没有额外决策价值。
Which Hand Was Late? 的实证要求保留这类强简单基线。
详见 [C 深审](deep-audit-active-diagnosis.md)。

## 4. 下一笔科研投入投向什么

**建议换研究对象：先考察在线自补偿的监督信号何时有效，不再为 ECCBF 寻找新名字。**
暂定探索问题：

> 同一台机器人机械状态不变、任务接触约束改变时，命令—执行残差驱动的在线更新，
> 是否会把任务所需的约束响应学成持续机械补偿？若发生，能否通过更新数据干预识别其来源，
> 区分控制饱和、归一化、普通遗忘与持久伪标签污染？

这是**等待现象与进一步查新支持的问题，不是已通过的新方法**。
选择它只表示有限探索预算比继续扩展旧四格实验更值得，不能保证最终选题或论文录用。

最接近的 [Self-compensating VLA §3/B.6](https://arxiv.org/html/2609.37334v1)
用执行残差形成自监督目标，真实实验在同任务 episode 间保留适配状态、任务边界清空。
它**已做抽屉任务**，不能声称没有接触。没看到拟议的任务交错污染实验，
也不能反推其方法已失效。窄探索对象是更新数据的因果作用与状态继承边界。

| 必须排除的解释/近邻 | 原始证据 | 对探索的要求 |
|---|---|---|
| 约束误差不应进入适配 | [Schwager–Annaswamy 2005](https://skoge.folk.ntnu.no/prost/proceedings/cdc-ecc05/pdffiles/papers/2854.pdf) training-signal hedging；经典 anti-windup/deadzone | 标准冻结/限幅/hedging 完全解释并解决时，不包装新 VLA 算法 |
| 依接触调制冻结底座动作 | [ViTaR Method](https://arxiv.org/html/2608.15816v1) | 触觉条件不同，仍否决“接触门控残差”宽主张 |
| 任务顺序下的性能变化 | [Continual VLA，ICML2026](https://proceedings.mlr.press/v306/liu26bu.html)；[FAN §III–V](https://arxiv.org/html/2609.21358v1) | 比较简单 replay 与固定 normalizer，排除坐标漂移 |
| 自生成目标的有效范围 | [SALT §4/附录J](https://arxiv.org/html/2610.07946v1) | 它已明确使原计划失效的变化超出监督范围；“伪目标可能错”不够 |
| 语言敏感仍可选错轨迹 | [Instruction–Action Binding §2–5](https://arxiv.org/html/2609.39971v1) | 若回到认知主题，正面对比其机制和 ECT，不能重复“并非简单忽略语言” |

**目前没有一个已证明超出这些近邻的新机制。**
不得提前以“约束感知校准”“因果门控”等名称当创新点。

## 5. 有限预算探索与真机进入规则

详细方案见 [探索实验登记](EXPLORATION_PROTOCOL.md)。建议最多两周研究时间盒，
环境/载体不通不计成科学否证，也不无限扩大训练。

1. 核对最接近工作的原文、代码、后续版本。若已经覆盖同一因果问题，停止探索该题。
   忠实复现、独立实现和概念试验明确区分。
2. 验收同一个 SO-101 策略的自由运动/接触任务能力与 RGB/q/动作时序。
   不从不会做任务的模型提取“污染”。
3. 仿真先作更新数据干预：恢复同一适配前状态与日志流，仅改变哪些反馈进入更新，
   再由匹配初态闭环执行。contact 真值只作解释与 oracle，不作为部署输入。
4. 第一阶段只比较 Frozen、忠实 self-comp、conditional adaptation、结束暴露后 reset。
   之后有信号再扩展 DOB、anchor/学习率、等数量随机丢样、replay 等；全部计入数据、更新和耗时预算。
5. 有可重复效应才进入真机。相同本体/关节目标/任务对，用实体导轨或挡片改变约束；
   真机验证同一个“更新数据→后续表现”对比，只用 RGB/q/命令可观测输入。
   不能仿真做机制归因、真机只播成功视频。

探索小样本只用于决策是否追加预算。20或40次运行不能预先承诺检出10个百分点的改善；
正式样本量依据配对差值方差、实际簇结构与最小重要效应决定。

## 6. 继续与换题门槛

| 检查 | 继续所需证据 | 停止/改研究对象条件 |
|---|---|---|
| 文献差异 | 原文未覆盖精确问题，经典同构方案不能直接替换 | 同核心仅平台不同，或把基准增列当方法 |
| 现象存在 | 机械条件固定，更新数据干预可重复改变后续表现 | 无效应，或仅时序、饱和、normalizer 错误 |
| 决策必要性 | 简单 reset/replay/传统 gate 无法同预算吸收全部收益 | 一个廉价现成方案已足够 |
| 核心增量 | 新可识别条件、新预测或方法，有失败条件与独立验证 | 只有视频、局部提分或工程流程 |
| 真机一致性 | 同一中心因果对比可实施并获得可解释证据 | 真机只能换任务展示 |

若探索失败，保存负结果和资产，停止该题；不把 anti-windup 更名为新 VLA 算法。
如果要求立刻冻结一个方法论文题目，**目前证据不足以负责任地承诺**。
现在能冻结的是淘汰结果、探索问题、预算与判定规则。
