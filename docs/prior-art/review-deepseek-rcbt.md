## 结论

**保留“跨任务误差结构是否可复用”作为研究问题；暂不采纳原稿的空白判断、动作偏差定义和 GP 配方作为主方向。**

## 3. 实质问题：单一参考动作会把正确多模态行为记成偏差

原稿定义 \(b(c)=\mathbb E[a(c)-a^*(c)]\)，并补偿 \(a'=a-\hat b\)。
考虑一个确定的任务，正确动作集合为 \(\{-1,+1\}\)，策略各以 1/2 概率选择它们，成功率为 1。
若选一条示范 \(a^*=+1\)，则 \(b=-1\)。按上式补偿，两个动作变成 \(0\) 与 \(2\)，成功率变成 0。

这是分析反例，不是机器人实测；数值核算见 [JSON](../../experiments/so101/rcbt-reference-counterexample.json)。
它说明：与某个 IK/示范动作不同，不足以证明有需要修正的策略偏差。动作均值可能落在所有成功模式之外。
这不反驳“唯一、预先规定的物理目标附近存在定位误差”，但否决了在任意 VLA 任务上直接采用该定义。

必须先选定与真实科学目标一致的对象，例如：

- 预先规定的唯一放置目标，使用目标坐标系内的实际物体终点误差；另报成功集合内的正常差异。
- 若任务允许多个正确解，则研究成功集合、结果分布或任务损失；改成这些对象后要重新查近邻，不能自动沿用“偏差场”新颖性。
- 低层 command–achieved 误差、策略动作相对某个示范的差异、最终任务误差分别记录。不能把三者混在一张 error field 图中。

只重复同样输入/同一随机流得到的确定输出不能估计随机分量。
配对方法可共享随机流以降方差，但重复单元本身须具有预定的独立随机性或独立硬件 reset block。
“偏差必须大于噪声才值得补偿”也不是必要条件；均值估计的误差还取决于有效重复数，不能只比较两项点估计。

### 3.1 由原文进一步得到的窄机制线索：语义变化不总要求当前动作分离

BAS-VLA §4.2 / Eq. (3)–(4) 使用 clean/control 模仿与语义破坏 triplet separation。
其 C.2 明确给出：当 separation loss 为零时，改变语义后的动作与 clean 动作至少相距 \(m>0\)。
这只是动作空间性质；作者也明确没有将其当成 rollout 正确性定理。

考虑“先共同抓起同一个物体，再分别放到左/右目标”这类任务。
若当前整个 action chunk 仍在两任务的正确共享前缀内，两条语义不同指令的正确当前动作可能相同。
此时完全正确的相同输出仍承受正的 separation penalty。
更一般地，若两个正确动作都必须在同一参考的 \(\epsilon\) 邻域内，则两者距离至多 \(2\epsilon\)；
要求 \(m>2\epsilon\) 的分离与同时满足这个正确性条件不相容。

**这给出一个比“加跨任务 GP”更具体的待检验机制：语义负例标签是否误伤局部共用动作，并诱发过早/无关的纠偏。**
它目前只是有明确条件的目标函数反例：未测 BAS-VLA 实际训练是否包含这些样本、实际 margin/单位是否进入该范围，
也未证明真实模型会发生任务损失。若 chunk 包含正确分支，或任务有足够多等价动作容纳分离，上述冲突不成立。

下一步优先检查动作/轨迹层面的 false-negative-aware contrastive learning、共享 primitive、时序语言相关性和 ECT，
再用共同前缀/分支后/无共同前缀三类任务比较。
BC、简单 phase gate、多正例对比损失若已解决全部问题，就不能把新门控包装为创新。
没有把“此处没搜到”当成空白证明，也不以这个反例推翻前作报告的实验结果。

## 4. 最便宜、最有决定性的对照

在一个已能完成任务的 SO-101 本体策略上，先检验以下三个竞争解释，不先训练新 GP 结构。

| 解释 | 对照 | 若对照已解释收益 |
|---|---|---|
| 实际是相同关节/工作空间位置的机械误差 | 仅用可观测 q、命令历史、估计几何的 pooled residual/GP；真值几何仅作 oracle | 不归因于因果任务相似性或认知偏差 |
| 实际是通用多任务回归的部分池化收益 | 局部 GP、全局 pooled GP、学习任务核的 MTGP/元回归、随机/打乱描述子 | 不将分层结构或参考类重命名为新方法 |
| 实际是单一示范/模式对齐造成的伪偏差 | 多个成功示范/结果集合；对照闭环任务损失与动作差异 | 先修测量对象，停止按原动作偏差扩大实验 |

所有可部署组只能使用同等级观测；不能让“因果描述子”读取隐藏接触或仿真材料参数，而外观基线只有 RGB。
来源任务的标定成本也计入预算，分别报告历史已有数据与为本方法新采的数据。

8×8 相似矩阵的 28 个非对角配对不是 28 个独立任务；8 个留一折的训练集高度重叠。
上下文/帧数不能替代任务数。报告任务级效应与不确定性，并按实际生成/分配设计做统计，不能直接套独立配对显著性。

## 5. 与用户“机制先行”偏好对齐的下一步

参考类迁移应先回答：**相同物理几何下，更换任务语义/接触要求后，系统性任务误差是否出现普通几何残差无法预测的稳定变化？**
只有出现这种效应，才值得研究哪些任务因素支持误差迁移；否则跨任务 GP 只是在学习已知空间误差。

同时，§3.1 的“共享正确动作却被要求分离”已单独整理为[共享前缀语义校准审计](temporal-prefix-calibration-audit.md)。
它应先作定向查新和失效验证，不与参考类 GP 或证书方法拼成大系统。

证据顺序应为：策略可用与误差定义 → 独立重复/成功多模态检查 → 几何解释与任务解释对照 → 留出任务迁移 → 方法设计。
这条顺序不要求先承诺 GP、参考类名称或心理学解释，也不把简单基线输赢预填成结果。

仿真与真机都检验**相同误差对象、相同参考任务到目标任务的迁移增益**。
若要演示“高相似/低相似目标”的差异，真机需包含已标定来源任务及两类目标，不能只有两个互不关联的成功视频。
小范围硬件结果只支持所测任务，不外推普遍迁移定律。
