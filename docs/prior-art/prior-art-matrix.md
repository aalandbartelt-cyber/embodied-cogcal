# 近邻工作逐篇证据矩阵

核验日期：2026-11-13。作者、版本、证据标签和代码提交见 [原始来源核验](verified-sources.md)。本表取代“本项目维度清单”；每行对应实际 paper。**ECCBF novelty 尚未通过**，差异列是实验义务；所有外部效果均未在本项目独立复现。

| 近邻与原文 | 已核实的最接近内容 | 校准位置 / 本体 / 代码状态 | ECCBF 待验证差异 | 不可直接比较的点 |
|---|---|---|---|---|
| [ICBench / IGAR](https://arxiv.org/html/2603.06001v2)，2026 | 固定场景矛盾语言；推理注意力校准；正常任务保持 | 内部注意力；LIBERO + Franka；M/T，代码未核实 | 可执行目标在独立执行条件下的交互及校准增量 | 无解矛盾下旧 SR 降低可以是改善，不能套用本项目主终点 |
| [LIBERO-CF / CAG](https://arxiv.org/html/2602.17659v3)，2026 | 可行替代目标；语言/无语言动作分支差；成功率与真机 | 推理动作引导；LIBERO + Franka Research 3；M/T/C | 超出仅增强语言影响的执行交互收益 | TF-CAG 与训练 VA 分支的 VA-CAG 信息/计算预算不同 |
| [BAS-VLA](https://arxiv.org/html/2609.23650v2)，2026 | matched clean/control/break；残差/门控；新旧目标分别计分 | 动作后校准；LIBERO + PiPER；M/T/C，部分设置公开 | 超出同预算 additive / generic residual 的交互增量 | 发布 adapter 的载体/动作规范不能直接接 SmolVLA/SO-101；不能横比论文数字 |
| [CorrectVLA](https://arxiv.org/html/2608.29967v2)，2026 | 失败分型；事后一句话转动作维度/幅度/时间窗 | 冻结动作偏置；LIBERO + xArm7；M/T，Code Coming Soon | 测试前冻结、运行时可观测的交互校准 | 人观察测试失败后的幅度与时间信息有额外预算；不覆盖全部失败 |
| [RAGu](https://arxiv.org/html/2611.10894v1)，2026 | 几何轨迹变换、策略兼容检索、冻结推理引导 | flow-matching；真实/仿真/跨本体；M/T，代码未核实 | 无检索依赖的明确交互估计及增量 | 源轨迹库与模型接口不同；同 SO-101 验证不等于跨本体能力 |
| [SO-101 Bench](https://arxiv.org/html/2610.36420v1)，2026 | SO-101 Isaac 数字孪生、同权重真机排名及绝对 SR 差 | 平台/评估；SO-101；M/T/C，主测试部分私有 | 本项目同任务/模型的仿真校准收益能否在真机保方向 | 不同于本项目 MuJoCo；排名一致不等于校准效应一致；项目/论文示范数口径不同 |
| [LIBERO-Plus](https://arxiv.org/abs/2510.13626v3)，2025 | 摘要核实七类扰动 | LIBERO 鲁棒性评估；M，官方仓库可读 | 扰动诊断之外的交互校准收益 | 未同等核查全文；CVPR 版直开 403，搜索摘要不作全文证据 |
| [LIBERO-PRO](https://arxiv.org/abs/2510.03827v2)，2025/2026 | 摘要核实四维扰动与记忆问题 | LIBERO 泛化评估；M，官方仓库可读 | 排除记忆/状态失配后是否仍有交互增量 | 未同等核查全文；不能凭摘要断言从未分析交互 |

六篇优先工作的相关正文已打开；没有把“未找到 interaction 关键词”当作不存在证明。现有证据不支持“首次具身偏差”“首次冻结动作校准”或“首次 SO-101 仿真—真机”。

保留当前路线的证据门槛：合法目标；首步不变性负对照；时间/状态/延迟可追溯的四格系统交互；两项校准任务之外的完整 held-out 任务；部署时无需真值的校准；公平 additive / residual 对照；同 SO-101 真机对照。均待实测，详见 [实验有效性](../EXPERIMENT_VALIDITY.md)。
