# 近邻工作差异矩阵

| 维度 | 本项目拟定范围 | 需要核对的问题 |
|---|---|---|
| 诊断对象 | 语言—观测冲突在执行条件变化下的行为变化 | 是否只测视觉冲突，还是显式建模交互？ |
| 机制量 | `b_sem`、`b_exec`、`b_int` | 是否已有同样的 2×2 反事实分解？ |
| 干预位置 | 冻结 VLA 输出之后的选择性动作校准 | 是否已有同样的门控和交互项修正？ |
| 本体 | SO-101 数字孪生与 SO-101 真机 | 是否已有相同本体和同一任务的验证？ |
| 主结果 | 受扰任务成功率提升，正常任务非劣效 | 是否只报告鲁棒性分数而没有成对恢复？ |
| 数据协议 | 同场景、同种子、四格匹配 episode | 是否存在泄漏或 privileged state？ |
| 对照 | 语义单独、执行单独、无交互项、placebo | 是否能排除普通残差和提示词收益？ |
