## 决策先行

**停止将当前 ECCBF 原型作为已选定的新方法；需要重新设计研究问题与机制。** 可以保留四格实验、SO-101 载体与日志资产，但不值得为现有“三向量+乘积门控”扩大正式 A100 矩阵。这个结论不依赖找到一篇完全相同的论文：现有实现本身严格等价于普通饱和因子残差，且当前显式作废计划协议存在无需学习的输入级消除法。

否决范围必须分层：

| 层级 | 判定 | 理由 |
|---|---|---|
| “反事实诊断→选择性残差修动作→真机”是核心创新 | **可否决** | 直接近邻已有这些机制，见下文原式核对 |
| “发现多扰动非加性交互”是核心创新 | **可否决** | 已有组合鲁棒性与闭环有限差分交互研究；标准四格差也不是新估计器 |
| 当前三向量校准构成区别于 ordinary conditional residual 的新方法 | **可严格否决** | 同输入/参数下的函数类完全相同，不是待实验决定的问题 |
| 已有工作做完“superseded-plan×3步命令延迟×SO-101”的确切实验 | **不能声称** | 本轮未查到同协议；Plus 甚至排除了语言组合，不能误引 |
| 任意更具体的跨任务机制都不可能新颖 | **不能声称** | 检索和数学等价性不构成全领域穷尽证明 |
| 当前已经存在值得以新方法名义先测的不可替代机制 | **没有** | 没有定义超出普通残差的新限制、识别条件或可预测量；效果尚为零证据 |

新颖性不足与“实验可能有用”不同。某个未测交互可以是有价值的现象，但不能反过来使已知代数成为新方法。

## 最接近原文：机制与边界

### 1. IDR：反事实诊断、动态门控与动作残差已经是明确方法

[原文 2607.25516v1，§IV-B Eq.(6)–(13)](https://arxiv.org/html/2607.25516v1#S4.SS2) 定义事实动作及图像/本体输入置零分支；两个动作差的 L2 范数作诊断，视觉差低于阈值时开启修正。Eq.(13) 为

\[
a_f=a_b+g[\alpha\Delta_{img}+w_{prop}\,\mathrm{clip}(\Delta_{prop},-\lambda,\lambda)],
\quad g=1[\|\Delta_{img}\|<\tau].
\]

这里是**每时刻在线**估计，语言保持为上下文；不是语义×外部执行扰动的离线四格估计。其“本体感知输入”也不能偷换成执行器动力学。当前 ECCBF 因而并非与 IDR 逐式同一算法，但“冻结策略、反事实动作差、诊断驱动门控、选择性残差修正”这一抽象层级无法再占有。§VI 明示三个前向的延迟成本，低成本离线近似只有在新预测/成本—效果优势明确时才可能另立问题。

### 2. BAS-VLA：合法语义变化和保留语义变化要分开

[2609.23650v2，§3、§4.2 Eq.(2)–(4)、§4.3 Eq.(5)–(6)](https://arxiv.org/html/2609.23650v2#S4) 的默认核心是冻结 VLA 上的 `a_br=a0+λrθ(a0,z(x))`，用 clean/control/break 匹配三元组训练模仿、相容与分离损失；保留语义辅助以阶段、视觉、语义、动作证据的乘积作门控，弱融合探针动作。默认不是所有分支一直开启。

它并未提出当前 S×E 四格场；但一般任务语义残差、匹配干预、正常能力保持及证据门控均已有近邻。当前 S 保持目标，不能拿其“应离开旧目标动作盆地”的 breaking 目标直接当本任务正解。**BAS 的题目/摘要或组件重叠不证明两者完全同一；ECCBF 也不能仅加一个 `se` 项就避开普通条件残差比较。**

### 3. CAG：同观察下语言诱导动作差与冻结策略引导

[CAG 2602.17659v3，§4、§5.1–5.2 Eq.(2)](https://arxiv.org/html/2602.17659v3#S5) 使用可行替代目标和相同场景，区分目标接触与完成；其公式为

\[
a_{CAG}=a_{uncond}+\omega(a_{cond}-a_{uncond})
=a_{cond}+(\omega-1)(a_{cond}-a_{uncond}).
\]

TF 通过去语言近似无条件分支，VA 另用视觉动作模块；不应把两种资源预算混为一谈。它增强给定语言相对视觉先验的方向，而当前长指令同时包含旧/新目标，直接增强整段语言并不保证去掉作废目标。它足以否决“反事实语言动作差指导冻结策略”为新颖性，但没有覆盖当前离线执行交互拟合。

### 4. Plus：组合分析有先例，但不能谎称语言组合已测

[Plus 2510.13626v3，§5.1 Eq.(3)–(8)、§5.2、Appendix F](https://arxiv.org/html/2510.13626v3#S5) 先以四条件成功率归一化构造 `P(Di,Dj|Y=1)`，再算条件协方差；它与 ECCBF 的原动作加法四格差**不是同一尺度/估计量**。在等比例抽样的表述下，该协方差的符号由 `p11 p00−p10 p01` 决定，非加法差 `p11−p10−p01+p00`。

§5.2 明确排除语言维度，只组合布局、背景、光照、相机、初始机器人状态、噪声。故“组合失效值得分析”已有先例；**“Plus 已测旧计划×延迟”无依据**。其成功条件化统计也不能替代本项目的随机化总效应、配对区间或认知因果识别。

### 5. PRO2.0：语言保持、执行时序、反馈和恢复已有交叉研究

[2610.24587v1，§4.3–4.4、Appendix A.4 Table 13、C.2–C.3 Tables 15–16](https://arxiv.org/html/2610.24587v1#S4.SS4) 包含固定时序/动作窗、短时延迟、陈旧 chunk、指令改写/重述。P10 组合 D18（可恢复掉落状态）+D20（目标/对象/顺序不变的重述）；T08 组合 S19（观测质量）+S21（同义改写）+D14（命令丢失/重复）。语言×机器人状态/执行的广义组合已不是空白。

其主组合量 `p(C)−min_i p(ci)`，原文明确说该量自身**不能**证明超出独立故障累积的交互。它没有给出当前作废计划的四格残差校准。反馈频率与 Hold/Retry/Reset 的存在要求本项目优先排除调度/恢复解释，而不能直接用其表格数字作本平台基线结果。

### 6. 新增关键近邻 IMPACT-VLA：闭环四格差已经直接进入方法

[2609.15005v1，§III-C Eq.(6)–(9)、§III-D Eq.(10)、§III-E Eq.(11)–(16)、§IV-A/E](https://arxiv.org/html/2609.15005v1#S3.SS4) 将阶段×模态块作为玩家，从相同初态闭环重执行；后续观测从受干预后的实时状态重新获取，**不重放参考观测**。其 Eq.(10) 是

\[
I_{ij}=E_{C\sim\nu}[V(C\cup\{i,j\})-V(C\cup\{i\})-V(C\cup\{j\})+V(C)].
\]

它还区分轨迹回归与任务功能恢复，并用独立上下文复核交互；研究对象是模态/阶段归因。**没有给出部署用动作修复器或学习交互残差校准**，也不是外部执行扰动×作废语义。因此不能说它完整预见 ECCBF，但“把局部动作对比升级为闭环非加性归因”已非剩余独占机制。

补充追引：[TAG §3.2 Eq.(2)](https://arxiv.org/html/2603.24584v1#S3.SS2) 已用原图与目标去除图的预测差作 CFG 残差；[ICBench/IGAR §3.1–3.2](https://arxiv.org/html/2603.06001v2#S3) 的部分指令无解，错误执行减少与当前可行目标成功率不可混用。[RSS 官方 ACL 页面](https://aclanthology.org/2026.acl-long.190/)进一步表明语言残差引导已有正式工作；本轮只读其摘要，未将其理论声称当已核公式。

## 原型逐式等价性：这里不是“可能太简单”

`metrics.py:49–58` 只取四格均值 `m00,m10,m01,m11`，再定义

\[
\beta_S=m10-m00,\quad\beta_E=m01-m00,\quad
\beta_{SE}=m11-m10-m01+m00.
\]

这是 `m(s,e)=m00+sβS+eβE+seβSE` 的饱和 2×2 回归重参数化。`calibration.py:70–89` 令 `u=s·1[s≥τ]`、`v=e·1[e≥τ]`，输出

\[
a'=a-r(u,v),\qquad r(u,v)=u\beta_S+v\beta_E+uv\beta_{SE}.
\]

1. **二元角点**：`r(s,e)=mse−m00`，与四格 lookup 偏置完全相同（基线固定为零，三个自由 d 维向量）。任何输入/参数匹配的线性残差模型，取特征 `[u,v,uv]`，都能逐样本产生相同输出。没有样本能区分二者；更高成功率也不能证明函数类创新。
2. **连续分数**：`r(u,v)=u(1−v)(m10−m00)+(1−u)v(m01−m00)+uv(m11−m00)`，即四格锚定残差的双线性插值。`u,v` 是概率还是强度尚未定义；把两者相乘不证明两故障独立，更不证明校准幅度可按概率线性缩放。
3. **数据/参数优势**：full 比 additive 多 d 个参数，并使用联合格信息。只打败不含联合项的 additive 是容量/可用数据优势的候选解释。公平比较至少要含同样 `[u,v,uv]` 的普通残差；那一项是恒等基线，应明确称作实现核对，不能期待 ECCBF 胜过自己。
4. **不是动态“场”**：当前类没有任务坐标、状态/阶段函数、执行强度参数化或跨任务约束。共享一个固定向量是很强假设，但“共享”本身不自动成为新的结构；不同任务方向可相互抵消。
5. **残差参考**：即使四格真是 target-relative residual，减 `mse−m00` 后仍留 `m00` 的平均误差；方法对齐的是基线，未必是零误差。若传 raw action，更不能把动作差当应移除偏差。
6. **识别未实现**：`from_factorial` 不检查 paired reset、合法目标参考、同一时刻、门控数据来源；`correct` 只接收分数，没有实现可观测检测器。接口文字承诺不等于已建立测量有效性。

已以 Python 标准库有理数核对四个二元角点与一个连续点，两种表示精确相等；没有把该数学验证算成 VLA 结果。

## 当前提示协议的更强反例：可以在输入层完全删除 S

生成器 `probes/generators/eccbf_factorial.py:87–91` 中：

```text
neutral: Current task: pick up the {target} block and place it in the green region.
conflict: Previous plan (superseded): pick up the {other} block. {neutral}
```

定义完全可部署的 `C(x)`：读取输入文本中明确的 `Current task:` 段，仅保留该段。它不读取 `condition_id`、`current_target_color`、物体真值或测试结果。对当前协议，**逐字符有 `C(x1)=x0` 与 `C(x0)=x0`**。这是文本形式上的确切结论，不需要推断“旧计划有没有可信度”。已用标准库对红/蓝两种模板实际核对，清理后均与中性文本逐字符相同。

固定同一执行条件 E、初态、政策缓存、推理随机数和环境随机数。如果两格均先经 C，且采用相同采样/调度时刻，则首次策略输入相同、预测相同；相同 plant 接收相同命令后状态相同，归纳至下一步，整个闭环轨迹逐步相同。因此 cleanup 方法的语义主效应和 S×E 系统交互都为零，目标保持也没有代价。若只是 wall-clock/token 成本不同，统一清理和测时后再比较。

**这不保证任务一定成功**：原策略在 E 下的机械失败仍可能存在。它证明当前 S 可被极简单独语义修复彻底移除，E 的修复无需一个语义×执行交互场。必须先比较 `C`、`C+queue repair`，再问复杂校准有何额外必要性。对自由文本、缺少可靠边界或真的执行中目标切换，此证明不成立；那属于新协议，必须另做查新和合法性定义，不能事后换协议保住旧贡献。

## 非零交互的三个非认知构造

**限幅**：令预限幅指令为 `0.4+0.4S+0.4E`，两个原因完全相加；执行限幅上界 1 后，四格为 0.4/0.8/0.8/1.0，四格差是 −0.2。故 final command/成功率交互不能反推内部认知耦合。当前校准类本身没有 clip；这是实际低层控制必须排查的系统混杂。

**plant 增益**：若策略 `uS=u0+Sb` 从不看到 E，plant `z+=gE uS`，则位置四格差为 `(g1−g0)b`。这是执行映射对同一语义方向的放大，未出现策略内部“具身认知场”。命令延迟同样可通过运动和后续反馈造成系统交互。

**反馈与时间**：延迟改变观测年龄、状态分布、执行前缀和剩余时间；额外探针改变 wall-clock、重规划频率或仿真暂停规则。平均不同时长/阶段的动作，可以仅因阶段错位得到交互。首步 raw prediction、限幅后命令、实测运动、完整 episode 成功率是不同对象，不能交替解释同一 `b_int`。

## 观测状态是中介，不能靠“匹配”消除后继续叫总效应

对隐藏动力学 E，关系是 `E→下一状态→RGB/q/history→后续 action`。若初始输入和 RNG 完全相同，未执行前 `aS0=aS1`，原始首步/整块的 E 主效应与交互必须是零。非零应先查输入、缓存、RNG 或条件泄漏。

闭环四格随机化可估计指定系统在指定尺度的总效应交互，**总效应本来包含状态中介**。把后续观测/状态固定为共同 replay，可测输入固定后的响应；若 E 不以其他输入进入策略，则此时政策对 E 的直接效应被设计为零。这不能推翻原系统总效应，只能定位其通道。

若按“都到达抓取阶段”的轨迹匹配，就可能条件化于受 S/E 共同影响的到达事件，产生选择偏差；不可删除未到达者。若四格没有共同状态支持，不应外推直接交互。更合理的诊断是预定 fixed-time 全样本总效应，加共同 replay/分支重执行的辅助分析，并明确它们回答不同问题。

## 最强简单基线与最小可推翻试验

顺序按淘汰价值排列。此处是待做设计，不是已获 A100 结果；不建议直接启动完整正式矩阵。

| 试验/基线 | 能推翻什么 | 通过要求或停止规则 |
|---|---|---|
| 纯文本 `Current task` canonicalizer；再与独立 queue/时序修复组合 | 当前语义干扰需要动作场处理 | 若同预算下达到同等/更好恢复，停止当前交互校准主张；文本等价已可静态验证 |
| 相同输入+RNG replay，只改隐藏 E，不执行 plant | “本体改变立即改变 raw 认知动作” | 必须零；非零先查工程泄漏 |
| 同 `[u,v,uv]` 普通残差与四格 lookup | 三向量构成新函数类 | 应逐样本等价；若不同是实现/拟合差异，不是创新 |
| global residual、semantic-only、execution-only、additive、普通 state/time conditional residual | 收益必须依赖交互结构 | full 必须在完整未见任务/强度胜过最强可用对照；相同输入、数据、调参、参数预算 |
| matched-delay、同执行前缀/频率、统一 queue、同暂停/时限，记录饱和前后 | 校准增量不只是更新鲜反馈/限幅 | 若时序或低层修复吸收增量，收缩为对应系统效应 |
| 幅度/触发率匹配的 shuffled/sign-flipped 交互 | 偏差方向具有特异性 | 真方向须在开发集冻结且 held-out 胜出；否则无机制证据 |
| TF-CAG、可匹配信息的 IDR/BAS 适配版 | 是否超出最近动作纠偏家族 | 匹配前向/训练/延迟成本；适配不能冒充作者原版结果 |

当前 task 标签实际上共享一个抓取放置模板，不能提供跨任务检验。先冻结真正不同任务谓词、独立 reset 组、合法目标计分、新旧目标结果以及运行时 gate 来源。任何上界实验使用 S/E 真值、未来状态或动作参考，均单列 oracle。

## 唯一还可保留的科学问题，以及为何它尚不能救方法

精确的问题可以是：**在目标固定、prompt 等价控制、时序与限幅明确后，语义干扰的任务相对误差是否随实际闭环执行状态产生可复现的非加性变化；该变化能否预测未见任务/强度上“修哪一部分才有效”，超出普通 conditional residual、文本清理和调度修复？**

这不是“是不是存在一个非零四格差”。成立至少需要：事先限定可观测量与状态支持；指定跨任务共享的结构和独立预测；以相同信息/预算打败无该结构的替代；真机冻结语义参数仍保持方法差值。四格均值、低秩词汇或门控阈值本身都不满足这些要求。

当前没有这样的可实施新增机制，且 IMPACT-VLA 已覆盖闭环传播/有限差分这一可能的宽泛退路。若只想做现象诊断，可以在少量仿真上检验该问题并接受负结果；**它不等于“创新已通过，先上 A100 再说”**。用户要求查新决定方向，按这一要求，当前应把 ECCBF 新方法路线判为未通过并重新设计，而不是用平台迁移或扩样本继续押注。
