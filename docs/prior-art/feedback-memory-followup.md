# 本体反馈、历史捷径与记忆评测：新增近邻约束

2026-11-14。完整目标仍是确定可查新、有先进性与可实现增量的方向；本页不是立项或查新结论。
这轮载体诊断不改变旧TPSC/补偿主张的证据门槛。
原文版本/范围/hash见[来源清单](../../experiments/so101/vla-open-source-audit/feedback-memory-followup-sources.json)。

## 1. “增加历史后学到错误线索”是老问题

[Causal Confusion in Imitation Learning，NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/hash/947018640bf36a2bb609d3557a285329-Abstract.html)
已明确指出额外信息可能在闭环分布偏移下恶化行为，并研究干预。
本轮只读该proceedings摘要/元数据，不声称重新完成其全文审计。

[Fighting Copycat Agents，§1、4–5](https://arxiv.org/html/2010.14876v1)
更具体地研究从观测历史恢复前一动作、用它低误差预测当前动作却无法切换行为的捷径。
其目标条件对抗器并非无条件删除全部历史信息，而是去除给定当前目标后仍多余的前动作信息。
因此“去掉q/history”“预测残差”“增加纠错记忆”宽泛方案不能当本项目新意。
本轮普通BC是否发生copycat仍未被识别；失败相似不等于机制相同。

## 2. 组合感知/动作/动力学补偿也已有直接工作

[Compositional Shift Algebra，§II–IV、VI–VII](https://arxiv.org/html/2609.13651v1)
使用精确reset、可分解的单因素探针，识别观测逆映射、动作映射和低阶动力学残差，再检验未见混合偏移；
动作延迟的非交换性与有序部署亦被讨论。故“分开标定视觉和执行后组合”宽题不能立项。

其范围很具体：已知机制族、可逆映射、固定延迟及可reset仿真；未建模接触和非平稳延迟在主范围外。
PickCube部分结果的动力学mix为0，收益来自观测/策略映射；不能用它证明普遍物理残差组合。
本文也有薄/深BC升级，因此不能简单把“改用learned policy”作为与它的差异。
本轮未取得可绑定源码/复现，也没有验证其性能。

## 3. 记忆开关的成功率差不等于正确使用了历史事实

[IMEP，§3、§4.1、§5与附录G/H](https://arxiv.org/html/2610.23372v1)
已有事实替换、同事实替换、精确重复与最小数值扰动的对照，并区分决策和运动结果。
它明确指出安装过程不一致、检索未命中被换记录、潜变量未验证语义等会限制因果归因。
框架/部分解释规则为事后形成，不能当全部campaign事前注册；ChainBench主要结果共享记录执行，
其单独事实特异性对照测试的是脚本reader，而非整个live写入—检索—执行链。

这些限制不消除其近邻地位。我们不能再把“干预记忆＋区分决策/执行”当空白；
也不能把本轮carry/reset的成功差直接表述为学到正确任务事实。
