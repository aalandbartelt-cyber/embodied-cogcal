# 接触条件下的执行残差自适配：换题初审

日期：2026-11-14。范围：针对“合法接触造成的 command–executed residual 会污染在线机械误差补偿”这一候选问题，优先核对 Self-compensating VLA 原文，并检索接触感知适配、无力传感器外力估计、残差 RL 与自适应控制。约束：单卡 A100、SO-101、优先 RGB+关节+命令，不默认力传感器；仿真与真机检验同一命题。未运行模型或机器人，未核算法实现代码；本文件为定向初审，不是穷尽查新认证。

## 结论

**宽题否决，窄问题可作限时失败验证，尚不能选为新方法主线。**

“接触反力不能一律当扰动消除”“接触/自由空间分模式”“估计接触后关掉更新/削弱补偿”“把残差投影到切向”“无力传感器估力”都有直接传统或近期近邻。加 contact gate、换到 SO-101、把目标写成 contact-aware self-calibration 均不足以成为贡献。

当前可能值得低成本先验证的是：**在线伪目标生成把任务要求的接触约束响应当成应永久修掉的本体误差后，是否造成跨 chunk/episode 的持续负迁移；在仅有 RGB+关节+命令、存在无法识别的样本时，哪些反馈有资格更新一个跨任务共享的执行模型？** 这种持续损失本身也可能只是经典 adaptive drift/windup 在 VLA 中的一个实例，不能称为空白。 这比“接触导致 tracking error”更窄，但目前没有新的可辨识规则或明显超越普通监督门控的算法。若简单 contact freeze、free-space-only 拟合、限幅/泄漏更新或按任务 reset 已经解决，停止新方法主张。

| 待声称内容 | 初审判定 |
|---|---|
| 机器人接触时残差不应总归零 | 已知控制问题，否决新颖性 |
| RGB/关节检测接触后选择性补偿 | 已有方法家族，否决宽泛创新 |
| 原 self-comp 在所有接触任务都会失效 | 无证据；它已测试抽屉操作，不能如此声称 |
| 其残差监督在某些合法约束下存在错误方向 | 可以给出数学反例；尚未证明实际 LoRA 系统发生有害学习 |
| 有限传感条件下所有机械/接触原因都可在线区分 | 一般不成立；需附加模型、可见几何或有辨识力的动作 |
| 当前已发现足以立项的新机制 | 没有；只能给一个尚待淘汰的窄研究问题 |

## 1. Self-compensating VLA 到底做了什么

[Taming VLAs under Robot Execution Errors: Self-Compensation and Stress Testing，2609.37334v1，§3 Eq.(1)–(3)、§5.3、Appendix B.2/B.5/B.6](https://arxiv.org/html/2609.37334v1) 的核心是

\[
\eta^{obs}=\Delta x-a,\qquad a^{target}=a-\eta^{obs}=2a-\Delta x.
\]

执行反馈监督 action-expert LoRA，基座冻结；参数锚定约束漂移。真实 Piper 使用关节绝对目标残差 `q_next−q_ref`，排除 gripper；不是力残差。原文有抽屉任务，也比较一个 Q-filter DOB；没有看到按任务合法接触分解残差/筛选伪目标的规则。

因此：**算法未显式识别接触残差，不等于论文没有接触，更不等于实际已经失效。** 其缓冲/优化状态跨多次评估保留，令长期污染成为可检验对象。未来工作提到外部运动测量；没有给出接触安全保证。论文单 A6000 48 GB 的计算记录仅支持规模参考，不保证任意 A100 显存和 SO-101 checkpoint 能直接复用。

## 2. 反例成立到哪里

设某时刻命令沿表面法向为 `a_n>0`，刚性约束使实际位移为零。原式给 `η_n=−a_n`、`target_n=2a_n`。若该任务已达到需要保持的接触状态，继续增加法向位移目标并非追踪进展，而可能增加内环接触载荷或饱和；这是把“受约束不动”当成“执行不足”的错误监督方向。

一个将伪目标近似直接拟合的标量学习器，若每次以 `2a_k` 作 detached target，小步更新可产生 `a_(k+1)≈(1+α)a_k`。**这只是结构反例，不是实际 LoRA 的发散证明。** 正式方法有小学习率、锚定、有限缓冲、不同观测和动作限幅，可能完全避免可见损害；也可能只造成接触后学习偏置。必须测部署算法，不能把 toy 递推写成真实结果。

此外，并非一切接触残差都该屏蔽。推开带阻力抽屉、克服可动对象静摩擦、建立所需接触力时，增加目标可能正是正确动作；保持壁面法向接触时，切向的本体误差仍可能需要补偿。接触与“该不该补偿”不是同一个二元标签。判断需要合法任务进度、允许的力/形变范围或可动约束，而非只看 tracking error 大小。

## 3. 观测可辨识性：RGB+关节不自动等于没有信息，也不保证足够

用一个准静态关节模型写出

\[
0=K(q^{cmd}-q)+d_{mech}+J^Tf_{contact}-g(q).
\]

只观测 `q_cmd,q,RGB`、又允许未知伺服增益/摩擦/接触时，数据主要约束 `d_mech+J^Tf_contact` 的和。把同一量从机械项移到接触项，可以保持同一关节和同一图像历史；存在遮挡/不可见接触时尤其如此。**无需假设传感噪声就能构造观测等价情形。** 即使知道合力，期望接触与应移除障碍仍需任务目标判断。

但“没有力传感器所以不可做”也不成立。若伺服/动力学已经辨识，位置/速度响应可估外力；可见表面几何、对象运动、已知柔性夹具的形变、自由空间试探或跨方向激励，也能增加信息。需要明确是哪条附加条件打破等价，而不是称一个神经网络能从信息相同的两世界恢复不同原因。

最低可识别条件应至少有一种：

1. 在已确认无接触且激励充分的轨迹，估计可跨任务保持的机械模型，并限定其漂移速度。
2. 从当下/历史 RGB 获得可靠的约束几何或对象运动，并有误差界；单凭“距离很近”不证明接触。
3. 一个幅度/成本受限的探针在两候选原因下产生不同可观测结果；若退一点/固定重试足够解决，就没有学习探针的必要。
4. 增加已校准的电流/力矩或独立形变信号；这改变了观测条件，应与原 RGB+关节设置分列。

在识别不足的窗口，输出“不足以更新共享模型”是合理决策，但拒绝更新/置信门控本身已有大量先例，不能直接当新算法。

## 4.1 更直接的传统红队：可能只是 windup 与错误适配信号

[Åström–Rundqwist，Integrator Windup and How to Avoid It，ACC 1989，§2–3](https://skoge.folk.ntnu.no/puublications_others/1989_Astrom-Rundqwist_anti-windup_ACC-conference.pdf) 已讨论执行饱和时内部状态继续累积、解除限制后长时间恢复，并给出 conditional integration、back-calculation 和实际执行输入反馈观测器。故“受阻继续学→释放后表现变差→冻结/回算改善”的故事本身远非新发现。

[Schwager–Annaswamy，Direct Adaptive Control of Multi-Input Plants with Magnitude Saturation Constraints，CDC 2005，§I–II Eq.(7)–(9)](https://skoge.folk.ntnu.no/prost/proceedings/cdc-ecc05/pdffiles/papers/2854.pdf) 更直接修改训练自适应增益所用误差：由已知饱和差构造辅助状态，再从 tracking error 移除其贡献，称为 Training Signal Hedging。它明确指出饱和误差会导致参数估计错误。这里不只是停止积分，已经是“哪些误差应进入适配”的机制。

[Ioannou–Sun，Robust Adaptive Control，§8.4.3 Eq.(8.4.31)–(8.4.33)、§8.5 的 dead-zone](https://flyingv.ucsd.edu/krstic/teaching/282/ioannousun.pdf) 在 disturbance 可能主导估计误差时停止更新，并说明需要扰动界及鲁棒性/理想收敛的权衡。本轮只读这些段落，不宣称通读全书。故“不能把无法解释的残差学进参数”也已有理论框架。

**接触约束不必等于已知 actuator saturation，神经 LoRA 也不等于积分器。** 仍可能需要识别未知接触、合法任务约束与机械变化；但若实验损失只在 clip/执行限制后出现，常规 anti-windup/hedging 同预算就解决，则应把结果归为已知问题的 VLA 实例。跨 episode 只是学习状态保留更久，单独增加这个时间尺度不能立新题。

## 5. 最强基线，不给新方法留虚假胜场

| 基线 | 信息/预算公平条件 | 排除的解释 |
|---|---|---|
| Frozen VLA + 命令/增量边界、执行滞后匹配 | 原动作接口、同控制频率/观测年龄 | 原始误差只是时序或过激目标 |
| 前作 self-comp + anchor，按原缓冲/优化节奏 | 原同信息，含精确伪目标、状态 carry-over；SO-101 版应标明适配 | 不能比较一个自己削弱的在线方法 |
| free-space-only 机械模型/线性残差，接触时冻结更新 | 相同 RGB 接触估计、训练样本与拟合预算 | 仅移除接触监督已足够 |
| contact gate + 全停止更新；按任务/episode reset | 门控只用当前信息；同时匹配减少更新次数的随机丢样 baseline | 改善来自少更新、少漂移或简单遗忘 |
| 切向投影残差+法向命令边界 | 法向由 RGB 估计；真值法向另列 oracle | 普通混合控制分解已足够 |
| 系统辨识+position-servo EKF/DOB+顺应外环 | 确有内环辨识，额外电流/力矩信息必须单列 | 神经适配只是模型/观测差异 |
| conditional adaptation / 已知饱和差的训练信号 hedging；buffer 排除接触样本、清空 optimizer/rollback、泄漏/投影更新 | 相同受影响样本与时延，固定开发集规则 | 所谓长期污染仅需常规数据生命周期管理 |
| reward-based residual RL | 有奖励时单列额外监督；同交互预算 | 任务目标监督是否直接解决歧义 |

真实力/接触真值、仿真约束 Jacobian、未来成功只能作为诊断 oracle，不得偷偷进入在线数据准入规则。无力矩接口时不把标准 momentum observer 伪装成“仅位置可直接运行”的 baseline；用实际可辨识的 servo 模型版本。

## 6. 可推翻的窄机制与失败验证

候选中心应是**反馈何时可以更新持久模型**，而不是 contact gate。可以先把所有 fancy 模块拿掉，预登记以下三个问题：

- H1：同样机械参数下，合法接触暴露会使 self-comp 的后续自由空间/新任务表现低于 frozen，而参数/优化状态 reset 能恢复；效果超出接触当下的限幅与时序影响。
- H2：门控/过滤能够保留真实机械变化适配增益，同时避免上述持久损失；随机同率丢样或简单 task reset 不足以解释。
- H3：同时存在接触与机械误差时，全部屏蔽接触会丢失可恢复的切向增益；一个明确模型/可观测约束能在未见几何/机械变化上选对更新方向。

**H1 不成立就停止以“伪目标污染”为核心。H1 成立但普通 freeze/reset 解决，最多形成失效分析/实践结论，不要包装新方法。H2/H3 都成立也不自动新颖，须再与控制、可观测性和在线学习原始文献逐式对照。**

要区分“补偿器提高接触当下压力”与“学习持久污染”：在接触暴露前后插入相同自由空间 probe，保留/清空 LoRA、优化器和 buffer 的独立消融；以接触样本比例作剂量，匹配总更新次数；用同一机械环境测试，不能把硬件参数同时换掉。

本轮不提出新控制器。可辨识子空间、持久/临时参数分开、数据准入或 rollback 都可能直接落入混合控制、投影适配和 training-signal hedging 家族；在观察到强简单基线无法解释的现象之前，为它们起新名字只会重演 ECCBF 的问题。

## 7. SO-101 与单卡的最便宜验证

先做不含 VLA 的小模型/现有控制器反例，确认实际残差符号、采样时刻、延迟对齐和学习方向；它只证明失效可能性，不能计为 VLA 成果。随后只有在已具备 SO-101 合格基础策略、任务成功率与同步日志时，才接 A100 跑小规模部署版。原文 A6000 48 GB 不能替代本地显存、推理/更新峰值与 30 Hz/异步调度核验。

同一低成本核心可用：自由空间到位、沿可见平面轻触滑动、可动对象带阻力推动。使用软/可变形夹具，并以 RGB 可见接触形变/对象进度作独立结果，不默认购买 F/T。软件注入可控 gain/bias/延迟可作为“执行映射变化”真值，但不得称复现真实齿隙/磨损；若要声称反力大小，需要独立校准的弹性形变基准，否则只报告形变、命令边界、任务结果，不能从 q_cmd−q 自证接触力。

仿真和真机都应包含机械变化×接触任务条件，并以**暴露后迁移损失/适配收益**为同一核心，而非仿真做接触归因、真机只展示成功视频。固定接触顺序、交叉平衡任务次序，报告初态与 buffer/优化器 carry-over；不能把学习变好与接触样本污染混到一条总成功率。

便宜真机是否可行取决于两个先决条件：已有稳定任务策略；RGB/编码器/命令时间同步能解析一个执行窗。若这两个条件未满足，问题卡在载体，不应通过换研究标题假装已经可测。对于精确力控或高精度插接，现有纯位置接口不宜先承诺能力。

## 8. 最小预登记观测研究：只发现/淘汰现象，不定方法优越

第一阶段仅检验 H1，不实现新方法。固定一个已能稳定完成的 SO-101 策略和单一机械条件，比较匹配的自由空间暴露与合法接触暴露。每个独立 block 都从同一基座、空缓冲和新优化器开始；暴露前后做相同物理 reset 的自由空间 probe。暴露中保留适配状态，probe 中冻结学习。记录命令、实测关节/RGB、时间戳、clip、buffer 样本、实际发生的更新数及参数漂移。

预登记方法只选四个：frozen、忠实 self-comp、约束/饱和时 conditional adaptation、按暴露结束 reset 适配状态。最初上限可设 **8 个独立配对 reset block × 2 类暴露 × 4 方法 = 64 个暴露单元**，每单元另含前后 probe；不能把 probe、chunk、帧当新增独立样本。若原 FIFO 没填满或没有实际更新，则不算有资格检验学习污染：延长至事先规定的更新次数，或据实记录载体失败，不能用“没有效果”否定 H1。

主终点为预定自由空间几何误差的 post–pre 变化，按真实配对 block 比较 contact/free 暴露与 self-comp/frozen 的差分；成功率和接触形变只作辅助。用固定窗和控制时刻，严禁只挑失败录像。机械误差恢复的另一个条件留到 H1 有清晰信号后再预登记 H2，避免小预算铺过多因子。

**这只是预算示例，不是样本量/功效论证。** 小样本可发现明显反例、审计伪目标方向或淘汰坏任务；不足以证明“无污染”、普遍失效、方法优越或 sim-to-real。区间过宽时结论就是不确定。设一轮固定资源上限并停止收集，禁止看显著性决定延长，也不能将试探结果当独立验证。若额外做模拟来筛条件，真机须使用另行冻结的条件；全部未见数据检验仍是后续阶段。

## 检索与证据边界

实际尝试 Scholar `"command" "contact" "online adaptation" robot`，工具返回不可访问，未见结果列表。普通检索覆盖 execution residual/contact、sensorless position-controlled force estimation、hybrid position/force、adaptive control/dead zone、residual RL、self-calibration/contact 等词组；主要判断只引用原始论文/作者稿。第三方对 self-comp 的评论也提到接触伪目标风险，但未用该评论代替实证或原文。

初审未发现“RGB+关节、无需已知模型、能普遍区分合法接触与机械误差”的已成立方法；这不能作为空白证明，因为一般设置本身不可辨识。也未发现足以认定本项目已有新机制的证据。**方向选择建议：不把 contact-aware adaptation 宽题直接立项；若愿意投入一个严格限时 pilot，只验证 H1 与最强 freeze/reset 基线，失败或被简单基线吸收即淘汰。**
