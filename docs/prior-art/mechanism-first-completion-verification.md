# 机制先行候选：动作表象是否诱发虚假完成判定

日期：2026-11-14。**候选问题，未通过查新，未测得模型失效，未实现新方法。**
用户保留 SO-101、A100、同体仿真—真机，并偏好“先发现失效机制，再提出针对性方法”。
本文件是正向机会检查，与 DeepSeek 的跨任务误差迁移并列；不恢复 D/D′。

## 1. 要验证的窄问题

> 当任务此刻的完成状态由独立物理判据固定时，机器人自己的姿态、可见性或结束动作风格，
> 是否会使可用 reward/success model 给出错误完成信号？按这个信号选择动作后，误判是否会放大？

科学对象是**当前完成判定**，不是所有“进度”或“价值”。物体不动时，机械臂靠近物体仍可能提高未来成功价值；
时间标注的过程进度也可以变化。因此“固定物体、评分变化”本身不是模型错误。
首轮只对齐到明确的当前放置谓词；不能把它说成完成了抓取/抬升等未观测的历史要求。

区分两种条件：

- 任务物体保持充分可见，姿态/结束动作风格改变：用于判断是否依赖任务无关表象。
- 物体被遮挡：用于研究信息不足时的错误高置信接受。失去证据后不确定性上升是合理行为，不能一律强迫分数不变。

## 2. 最近工作已经覆盖什么

| 一手来源与本次阅读范围 | 已覆盖 | 本候选不能宣称的新意 |
|---|---|---|
| [Robometer，2603.02115v1 §III/V/E.2](https://arxiv.org/html/2603.02115v1) | 过程进度、当前 success head、轨迹偏好；稀疏视频和隐含物理状态的局限；success 阈值用于终止 | 不是首次 reward/failure model；不能将其逐帧时间进度直接当物理完成标签 |
| [RoboReward，2601.00675v2 §4.2](https://arxiv.org/html/2601.00675v2) | 明确的末状态 1–5 分 rubric、反事实改指令及 negative clipping | 反事实数据本身不是新方法；5/5 的当前完成判据可作为本候选的可核对象 |
| [AnyviewMeter，2609.20106v1 §III/IV](https://arxiv.org/html/2609.20106v1) | camera-ray conditioning、同步多视图注意力、姿态/FOV 变化下的 reward 适配 | “同一状态不同视角评分不同”“加几何/多相机”已被覆盖，不能当空白 |
| [GORDON，2608.03753v1 §III/IV.B](https://arxiv.org/html/2608.03753v1) | robot 节点/边屏蔽、对象关系 reward，已专门对照 robot-dominated motion | “去掉机器人视觉变化”不是新机制；robot mask/对象图是必需强基线 |
| [MONA，2501.13011v1 §4/C.3](https://arxiv.org/html/2501.13011v1) | gridworld 中挡摄像机绕过终止规则的 reward hacking 及缓解 | “行动能改变监督者所见并获利”不是新发现；它不是当前 SO-101 学习型视觉判定器实验 |
| [Rollout then Recycle，2611.03168v1 §5](https://arxiv.org/html/2611.03168v1) | 明确指出时长/尾部空闲动作泄漏标签、相机差异泄漏策略身份、相机行应按 episode 分组拆分 | 这些泄漏是作者已报告限制，不能当我们新发现；必须在数据处理时排除 |
| [CriticHack，2610.02527v1](https://arxiv.org/html/2610.02527) | 在 MuJoCo 把视觉 reward 的错误对象高分、策略优化后的错误对象放大、aggregate AUROC 掩盖语义误排和 task-specific verifier 修正做成闭环实验；还含 sim-to-real case study | 不能再把“视觉完成判定会错误接受并被优化放大”作为新核心；本项目若继续只能做不同的可识别失效条件或同体 SO-101 复现/边界研究 |

尚待检验的区别是：**当前可部署学习型判定器的动作可控误判路径、其决策影响是否在 SO-101/不同输入协议下呈现新的可识别边界。**
CriticHack 已覆盖错误对象语义放大与 verifier 修正，因此“再加一个 verifier/robot mask”不再是候选方法；继续工作只能先做同体复核，或寻找其未覆盖的具体失败机制。
没有从“没看到同标题”推出无人解决，也没有先承诺一种新算法。

## 3. 已执行的同体静态预检

证据：[原始记录](../../experiments/so101/visibility-precheck/summary.json)、
[接触表](../../experiments/so101/visibility-precheck/contact-sheet.png)。
固定现有 SO-101 MuJoCo 场景，采样 240 个机器人构型、两个物体放置状态和两个相机。
剔除涉及运动机器人部件的负距离接触构型，得到 **744 条静态可见性记录**。
每个物体状态内保持物体位置不变，仅改变机器人构型；用 segmentation 比较正常渲染与隐藏机器人渲染的红块像素数。
八张图是各标签/相机下可见比例的最大/最小样本，**不是八个机器人任务回合**。

这只证明能构造受控视图与独立放置判据。
未验证这些构型之间的无碰撞运动路径，物体状态由 reset 直接设置，没有 reward-model 分数、闭环策略或真机数据。
隐藏机器人只用于可见比例的 evaluator 参照，不能作为真实相机输入或物理可执行性证明。

## 5. 最小验证顺序与强基线

1. 确认各输出语义：当前成功、过程进度、未来成功价值分别存储；用公开真实 SO-101 小样本做正常能力检查。
2. 在冻结模型/原始阈值下评估配对物理判据；分别测试充分可见与被遮挡条件。只在独立校准集设阈值。
3. 排除时长、帧数、任务指令和 camera ordering 差异；用 length-matched/random-cut、原始模型、简单校准、robot mask/对象图、多视图平均和几何适配作对照。
4. 若确有稳定误判，才检查动作优化能否在**可达且不改变物体判据的真实仿真轨迹**上利用它。
   静态构型得分搜索只能叫 susceptibility test，不能叫机器人学会 reward hacking。
5. 只有在简单基线不能吸收效应后，才设计针对该路径的因果补偿方法。可能的技术对象是任务保持姿态干预引起的判定偏移，
   不预设 GP/LoRA/门控，也不把它们串联成创新。

主终点为错误完成接受率、真实任务成功、风险—覆盖、额外数据/计算/动作成本；
paired scene 与 episode 是分析单元，帧/相机不是新增独立样本。
不同物体、布局、任务和策略按来源分层留出，禁止在同一张扫描图上选阈值再报告泛化。

## 6. 真机检验同一个机制

同一台 SO-101、同一放置谓词、同一动作/相机时序；在物体已固定为完成/未完成状态时，执行经验证的非接触姿态变化。
由独立参考视图或标定标记确认对象状态，判定器只见预先规定的部署视图；参考真值不作为方法额外输入。
若后续采用双视图方法，所有相关基线也使用双视图。

先验证配对误判，再验证修正及其对实际停止/继续决策的影响；不能仿真只测模型评分、真机只播成功视频。
若大幅度效应只在不可见状态、错误 prompt、随机合成图或连接路径无效时出现，不能支持拟议机制。

## 7. 当前裁决与进入方法设计的门槛

当前完成判定线降为**强对照/复现实验线**，不再与 TPSC 并列主推荐。静态可见性预检仍保留，因为它可用于构造配对场景；但它不能提升该线的新颖性等级。

- 近期/经典近邻未覆盖同一核心机制及拟议修正，而不仅是没用 SO-101。
- 至少一个强开源判定器在语义正确、输入协议正确、独立场景上出现可解释的物理完成误判。
- 错误不是全部由普通遮挡信息不足、视频尾部标签或粗糙阈值解释。
- 相同信息/数据/算力下，简单 robot mask、多视图或标签清洗不能完全解决。
- 同体真机能按上述配对条件验证。

当前只完成来源与几何预检；上述模型/决策门槛未达成。完整研究选题目标保持 active。
