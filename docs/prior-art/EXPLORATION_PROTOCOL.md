## 1. 只检验一个主问题

同一机械条件下，合法接触暴露后，残差自监督更新是否导致后续自由运动的持久性能损失？
该损失能否由更新状态 reset 或经典 conditional adaptation 同预算消除？

第一阶段不训练新 gate，不提出新 acronym，不混入语言矛盾、视觉腐蚀和随机延迟。
已知机械变化适配收益、接触切向收益和新方法优化都留待主问题存在之后。
背景与反例边界见 [接触深审](deep-audit-contact-adaptation.md)。

**进入前再查新**：先检查 self-comp 作者的后续版本/代码、training-signal hedging、
接触/自由空间混合适配和 continual VLA 的直接引用链。发现同一核心因果实验已做则停止立项，
不以 SO-101 或新增真机视频继续同名方法。

## 2. 载体和任务前提

- 优先保留单 A100、SO-101、RGB+关节位置+命令和时间戳。先验不包含 F/T、力矩或触觉接口。
- 一个已经验收的多任务策略须能完成自由运动与所选接触任务；不能直接把 LIBERO 7D Cartesian 输出发给 SO-101。
- 自由运动可用若干可重复的到位/移物目标；接触可用软导轨约束下的推移或轻触后沿表面滑动。
  夹具几何和任务终点由独立 manifest 定义。正式任务由实际基线能力和可视性决定，不先承诺精密力控。
- MuJoCo 只复现接口和受约束运动，不预先声称精确复现舵机摩擦、齿隙或磨损。
  gain/bias 注入应称执行映射改变，不能改名物理磨损。
- 真机记录关节几何误差、对象位置/形变、任务结果和命令边界。没有校准力测量时不从 qcmd−q 自证反力。

验收报告至少记录：checkpoint/hash、相机视角和频率、q 单位、动作绝对/增量、normalizer/hash、
队列/控制周期、观测年龄、clip 前后命令、实际发送/生效/读取时刻、推理与更新峰值显存/耗时。
基线能力不够或更新无法发生属于载体未就绪，不计成“没有污染”的科学结论。

## 3. 最小主实验：64个暴露单元的预算示例

| 因子 | 水平 |
|---|---|
| 独立 reset block | 8 个，每个 block 有独立初态/随机种子；不是8帧或8chunk |
| 暴露 | 自由运动 F；合法接触 C，机械参数相同 |
| 方法 | Frozen；忠实 self-comp；conditional adaptation；暴露结束后 reset 适配状态 |

共 8×2×4=64 个暴露单元，每单元另含固定的前测/后测；它们不额外算独立样本。
这是资源上限示例，**不是功效计算，也不是已执行的注册**。
先做耗时测量，再一次性冻结 block 数、每单元长度、分析与停止时间；不看显著性追加样本。
若资源不够，缩小探索声明并报告不确定性，不通过伪重复凑样本。

每单元顺序：

1. 加载相同基座、零效 LoRA、新 optimizer、空 buffer、固定 normalizer；重置物理状态。
2. 前测自由空间 probe，冻结更新。probe 是固定评估轨迹/目标，不是学出的物理诊断动作。
3. F 或 C 暴露；按方法更新。忠实 self-comp 保持前作实际伪目标、缓冲、锚定与调度。
4. 记录实际进入 buffer 的条目与更新次数。若本应更新的self-comp未填满buffer/没有更新，
   不据此否定学习污染；全部结果仍保留，按事先规则标记载体未就绪或整个匹配block无法检验机制，
   不事后只删不利单元。conditional adaptation有意拒绝更新属于其方法行为，不能作为排除理由。
5. 重置到前测的匹配物理初态，适配状态按方法保留/清空；后测期间冻结学习。
6. 保存完整状态和失败单元，不因任务失败而删除日志。不同方法/暴露在block内采用预先生成的
   随机平衡排列，记录分配seed和实际顺序；随机化分析必须使用实际实施的分配规则。

Self-comp 原论文在任务边界 reset；本方案把“接触暴露→自由运动测试”作为**额外的状态继承压力测试**，
不把超出其报告协议的失效说成推翻原论文结果。另保留按原任务边界 reset 的忠实协议作为参照。

conditional adaptation 先用明确的执行边界/饱和检测规则，或固定 RGB 约束识别规则。
部署规则只见 RGB/q/命令历史；若用仿真 contact 真值则明确改标 oracle，不能混在可部署组。
“全部接触关更新”只是简单对照，不是假设正确答案——有些带阻力任务确实需要补偿。

## 4. 主终点与中介检查

主终点：固定自由空间目标序列的几何终点误差，取每单元后测减前测的变化 d。
在每个独立 block 内，主对比为

```text
Q = (d_selfcomp,C − d_selfcomp,F) − (d_frozen,C − d_frozen,F)
```

正值表示适配状态可能带来额外的接触暴露后损失。这个估计对象只针对冻结的暴露协议，
不能从非随机自然任务序列外推所有任务。预先定好距离单位、关节/末端空间与汇总权重。
辅助结果为成功率、接触任务进度、形变/命令越界、更新数、参数漂移和耗时；不能事后挑最好指标。

即时恢复检查只改变参数/LoRA。后测冻结学习时，单独清空optimizer或buffer不改变当前推理；
要识别二者的作用，需另设恢复更新、提供匹配新数据流的分支，单列为后续适配效应。
同时检查低学习率/anchor是否已足够；
时间对齐、clip、正常静摩擦克服是否解释表面损失。小样本区间很宽时结论就是不确定。

分析单位是 reset block。报告所有 block 的配对差值、均值和适合小样本的区间/随机化分析，
明确方法条件；不以数千帧获得虚假极小 p 值。若将来增加任务/训练种子，按实际层次建模或聚类。
正式验证所需样本量由探索方差与最小重要效应规划，不沿用64个单元当论文充分性证明。

## 5. 数据干预：避免只看到相关性

若主实验出现稳定损失，才追加如下机制检查：保存一个真实在线更新前的完整参数、optimizer、buffer、
RNG、normalizer 与物理状态快照，从同一状态分支，改变一次更新所用的反馈样本，之后从匹配初态闭环测试。

- 全部样本；排除所选接触窗口；等数量随机排除；只移除已知饱和贡献的传统训练信号修正。
- 匹配更新次数、样本数、梯度步与数据年龄；否则“排除接触”可能只是减少学习。
- 接触标签仅用于离线因果诊断；测试部署 gate 时必须换成可观测版本并单列其误判。

这是一批更新的因果干预。**固定日志重放不是整个在线策略的反事实复现**：在线参数会改变后续动作和数据，
重放只能检验该冻结数据流/该更新的作用。若要声称整段策略效果，应重新执行闭环并计入反馈分布变化。
不能沿参考轨迹喂入旧观测，然后声称重跑了新策略。

## 6. 有信号后的强基线扩展

第一阶段不是方法竞赛。仅当现象存在且不被简单对照吸收，才为以下比较分配新预算：

| 比较 | 排除什么 |
|---|---|
| DOB/已辨识 servo 的观测器 + Frozen | 是否只是已知低层追踪问题 |
| anchor/学习率/泄漏/限幅、known-saturation hedging | 是否只是 adaptive drift 或 windup |
| 同率随机丢样、相同更新计数 | 是否只因少更新而改善 |
| 简单 replay、按任务或 episode reset | 是否只是常规遗忘/状态生命周期管理 |
| 固定 normalizer 和 action-coordinate 对照 | 是否来自 FAN 已研究的坐标漂移 |
| 同信息 free-space-only、RGB 接触 gate、切向投影 | 是否成熟模式分解已经足够 |
| oracle contact/几何/执行映射 | 区分信息不足和算法不足，不能作部署优越证据 |

额外示教、奖励、力/电流传感数据必须单列，不能把信息优势当方法优势。
全部耗时包括暴露、probe、reset、推理、在线更新和失败重试。

## 7. 真机必须怎样对应仿真

| 核心元素 | 仿真 | SO-101 真机 |
|---|---|---|
| 问题 | 接触反馈进入更新后对后续表现的作用 | 同一个对比，不能换成静态抓取演示 |
| 机械条件 | 同一参数/映射，明确注入位置 | 同一机器人与控制配置，记录漂移；不假装完全无漂移 |
| 约束改变 | 软导轨/挡片几何 | 对应实体夹具与可测几何 |
| 输入 | RGB/q/命令时序 | 相同含义与单位，实际频率可不同但登记 |
| 中介 | buffer/更新快照、接触真值仅解释 | 同类更新记录，接触依据来自独立标注/可见形变 |
| 终点 | 同一前后测几何误差与任务谓词 | 校准 RGB/关节几何测量与同一任务条件 |

真机恢复姿态不等于重置温升、回差、物体/夹具状态。冻结预热/冷却和复位检查，随机平衡顺序，
记录可测温度、关节追踪响应与夹具状态。Q首先只反映“适配×暴露”的总差异，不能单凭它隔离软件学习。
要归因到更新数据，真机还需执行匹配的软件状态分支：在相同暴露后的配对测试中随机切换初始/暴露后参数，
或从同一更新快照作反馈删除干预，再用相同后测协议；不能只记录buffer而不实施干预。
两次物理执行无法完全同步隐藏机械状态，报告配对残差与限制；若差异被机械carry-over解释，停止强因果声称。

先在仿真冻结方法、任务、窗口和分析，再用新初态做真机验证。若真机误差主要由不匹配接口或任务不会做造成，
先修载体；不选一段成功视频作为机制支持。若需要估计接触力，另行明确传感/标定条件，当前方案不做此承诺。
