### 2.2 FIERL，arXiv:2405.04938v1

正确题名为 *Fault Identification Enhancement with Reinforcement Learning*；[摘要/版本](https://arxiv.org/abs/2405.04938)、[全文](https://arxiv.org/html/2405.04938v1)。HTML 题名缩略词渲染不全，不能据此改论文题名。本轮精读 §II/IV/V-B/VI/VII，核 §III 约束定义、V-A 估计公式与参考文献链。

\[

\[
\max_\pi\;\mathbb E\sum_t\gamma^t\mathcal M(z_t^{est},z_t)

| 项目 | 定位 |
|---|---|
| 算法 | 分离任意被动诊断器与输入设计，用 constrained policy optimization 优化诊断准确性，控制跟踪退化作约束；可输出整体控制或附加探测信号。 |

| 实验 | 三水箱线性化模拟，连续执行器故障；与同跟踪约束调优的比例控制+随机输入比较。训练恒定故障，测试跳变故障。 |

## 3. 经典引用链进一步压缩了空间

### 3.1 主动故障诊断不是新原理

- [Raimondo、Braatz、Scott，ECC 2013 原文](https://skoge.folk.ntnu.no/prost/proceedings/ecc-2013/data/papers/0627.pdf)：本轮读摘要/引言，不声称逐式精读；其摘要已明确闭环反馈减少使故障可辨识的时间/代价，维持有限时域保证。
- [Raimondo 等，Automatica 2016 原文](https://web.mit.edu/braatzgroup/Raimondo_Automatica_2016.pdf)：已读 §2 的 reachable output set、§3 diagnosis guarantee 与 Eq.15–16。离散仿射候选模型、已知有界噪声/初态；输入使候选可达输出集分离。这正是“给可辨识条件与可行探针证书”的经典母题。
- [Paulson、Martin-Casas、Mesbah，IECR 2017 原文](https://static1.squarespace.com/static/5d4488dc0d24df0001719b1f/t/5d5a143efd93c4000195f33b/1566184517942/IECR2017.pdf)：已读 pp.9594–9595 的 Bayes risk、Problem 1及在线重规划开头；有限已知非线性故障模型、参数/初态/噪声分布已知，最小误判概率，硬输入与机会状态约束。
- [Online input design … concave minimization，arXiv:2401.05782 原文](https://arxiv.org/html/2401.05782)：已读 §2–3、§4 开头；belief由各模型状态估计+后验构成；Eq.26 用先验权重与 Bhattacharyya 系数近似误判界做闭环输入设计。不应只比随机动作而略去这类有限库模型辨识。

本次用统一符号概括其共同机制（**概括，不伪称某篇原公式**）：

\[
u^*=\arg\min_{u\in\mathcal U}\Pr(\hat H\ne H\mid u),
\quad\Pr(x_k\in\mathcal X\mid H_i,u)\ge1-\epsilon,
\]

或要求 \(\mathcal Y_i(u)\cap\mathcal Y_j(u)=\varnothing\)。因此，“信息增益/候选输出分离+安全约束”已经是既有路线，不是现在的创新答案。

### 3.2 按修复价值选择探针也不是新原则

最关键原始来源：[Breese & Heckerman，*Decision-Theoretic Troubleshooting: A Framework for Repair and Experiment*，MSR-TR-96-06 / UAI 1996](https://www.microsoft.com/en-us/research/wp-content/uploads/1996/03/Decision-Theoretic-Troubleshooting-A-Framework-for-Repair-and-Experiment.pdf)。已读 §2.3、§3、§4–5，含 PDF pp.8–13 决策公式；非仅题名/摘要。

其 observation 方案直接计算

\[
ECO(I;o)=C_o+\sum_kP(o=k\mid I)ECR(I\cup\{o=k\}),
\]

配置干预+观测的原文 Eq.1 为：

\[
\begin{aligned}
ECCO(I;o_i;c=m)={}&C^s+C_i^o\\
&+\sum_{k=1}^{r_i}\Pr(o_{i,post}=k\mid c_{post}=m,I_{pre})\\
&\hspace{1em}\cdot ECR(I_{pre}\cup\{o_{i,post}=k\}\cup\{c_{post}=m\}).
\end{aligned}
\]

\(C^s\) 包括改变并恢复配置的成本。每步在 repair、observation、configuration–observation 中选期望成本最低者。Persistence network 区分干预前后，避免把动作后的变化当成原始原因。其计算近似有单故障等假设，但**测试的目标是低成本修好而非认清标签；动作可能改变证据**，并不是 2026 年空白。

更早的 [*Troubleshooting Under Uncertainty*，MSR-TR-94-07 原始机构记录](https://www.microsoft.com/en-us/research/publication/troubleshooting-under-uncertainty/) 本轮仅核摘要/元数据；作者副本 PDF访问超时，故不从它转述公式。1996 全文已足以否决“首次用修复收益替换信息增益”的宽泛主张。

### 3.3 dual control 的原始历史定位

[Feldbaum，*Dual control theory I*，1960 原始期刊记录](https://www.mathnet.ru/eng/at12624) 与 [Part II](https://m.mathnet.ru/php/archive.phtml?jrnid=at&option_lang=eng&paperid=12665&wshow=paper) 已核验题名、年份、摘要；俄文 PDF 未精读。只据原始摘要确认：I 引入 closed-loop dual-control 最优问题，II 给出一般算法并比较开闭环。本报告**不声称从俄文全文核过现代 belief-space 公式**。任何“动作兼顾控制和信息”的首次性表述均不应采用。

## 6. 精确决策对象：用来否证，不能包装成新算法

以下是本次统一建模与推导，**不是文献新颖性结论**。

令故障 H、允许的完整被动历史 \(Y_0=(RGB,q,a,时间戳)\)，探针 p 后新观测 Z，修复动作 r。直接修复风险为

\[
R_0(y)=\min_r\mathbb E[L(H,r)\mid y].
\]

若探针改变物理状态，必须将转移后的状态纳入损失 \(L(H,r;p)\)，并计全部探测/复位成本：

\[
R_p(y)=c(p)+\mathbb E_{Z\mid y,p}\left[\min_r\mathbb E[L(H,r;p)\mid y,Z,p]\right].
\]

只有 \(\min_pR_p<R_0\)，主动探测才有决策价值。该式就是经典 value-of-information / troubleshooting 形式，**不能重新命名后作为贡献**。它能改变决策：当所有假设的最优修复相同、通用升级足够便宜、或探针毁坏了可恢复状态时，应直接修复/升级，不应探测。

一个最小可证伪命题（尚未发现满足它的实机任务）：在固定预算 B、同一故障持续存在的单臂任务上，存在被动近等价而修复互斥的两种世界，使受约束探针后修复的恢复率，比训练预算相同且可选择所有合法修复/升级的最优简单无探测策略高至少预登记的 δ；并且学习机制相对**经验 Bayes 的有限探针库搜索**仍有独立增量。δ 的数值应依据先导噪声及样本量确定，不能先填一个好看的百分点。

这里前半句只是验证主动诊断是否值得做，后半句才开始触及方法空间。**本次没有获得使后半句成立的新机制证据，故不能由此宣布 C 通过。** 如果任务只含两故障、两探针，查表/穷举已足够，不需要为满足“A100做模型”强行训练复杂模型。

简单必要条件可作审计：两故障等先验、被动分布完全相同，选错修复损失 Δ，正确为0，则任何被动规则风险至少 Δ/2；探针错误率 η、总成本 c，主动风险至多 c+ηΔ。只有 c<Δ(1/2−η) 才可能值得探测。若允许“同时修好两种”的 rBoth，必须把它放进 r 集合重算；这可能直接消除所谓缺口。这个推导是基础决策论，不是拟议新定理。

## 7. 低成本可试的窄问题与为何尚不推荐立项

可只做一个实物先导：遮挡内槽中的左右两种可替换导向片，使轴向插入在相同可见外观/接触面停住，但正确恢复需相反方向的小幅退让/平移。用一只 SO-101、固定 RGB、编码器与命令时间戳；探测只采用有限、小位移、可撤回的横向动作，以位移响应/图像响应取证。不需要力传感器。

硬件接口前提已另查官方一级来源：[LeRobot SOFollower源码](https://raw.githubusercontent.com/huggingface/lerobot/main/src/lerobot/robots/so_follower/so_follower.py) 的 `observation_features/get_observation` 默认读 `Present_Position` 与配置相机，`send_action` 写 `Goal_Position`，可按 `max_relative_target` 截断后返回实际发送动作；[官方API](https://huggingface.co/docs/lerobot/main/api/robots)亦如此。**这证明默认接口支持本报告的信息集，不证明每台SO-101物理上完全没有其他可读寄存器。** 部署时需固定版本，审计实际发送动作与额外反馈，不能把“指令被截断”误诊为接触故障。

**这是待建构的反例装置建议，不是已验证硬件事实。** 必须先证明：实际 q/跟踪误差没有在原动作里泄漏导向片类型；错误修复确有独立物理代价；两方向全部试一遍在真实预算下不占优；探针不会把另一世界直接修好而只是获得更多信息。不能靠人为禁止合法升级、隐藏已有传感器或事后缩短 baseline 时限制造难题。

它的价值在于最快否证 C 的任务前提。即使成功，也仅得到“该单臂受约束任务确需主动信息”的证据；传统有限库 input design/排障可直接求解。除非出现一个简单方法无法处理、可重现且有结构性解释的机制障碍，否则仍应换主路线。

## 8. 严格验证“被动不可辨识”的方法

1. **先声明信息集**：包括所有可获得的 RGB 帧、关节位置/差分速度、命令、执行反馈、时间戳、夹爪状态及跟踪误差。若真实系统能廉价记录某量，应给最强被动基线；不要只让 VLM看两帧再说全被动不可能。
2. **仿真结构证明**：构造 h0/h1，使基策略访问到的状态上观测映射及后续输出转移相同；共同随机数耦合相同初态/扰动/渲染，检查原始 history 而非编码特征。仅“分类器≈50%”不是不可辨识证明。
3. **近似情形讲清上界**：若两个 history 分布总变差≤ε，等先验下任意分类器错误≥(1−ε)/2。这是数学条件，有限样本不能因未拒绝差异就当证实；可做强序列分类器、二样本检验、泄漏审计，作为对结构论证的反证搜索。
4. **修复反事实矩阵**：仿真从相同失败状态/相同 H 出发，执行每个合法 repair 与组合；证明 repair ranking 真随 H 改变。H 在探测和修复阶段不得重新抽样。真机用可复现夹具与随机盲配配置，测完整矩阵及波动。
5. **探测信息与直接改善分开**：探针后把 Z打乱/遮蔽，但执行相同动作；若收益仍在，收益来自物理重新定位/额外尝试，不是辨因。另设只采集同等时长被动帧与只换视角组。
6. **坚持同一命题**：仿真和真机都测“匹配被动证据、相反最优修复、探针响应分离、同预算恢复增量”四件事；不能仿真测识别、真机只播一个成功恢复视频。

## 9. 最强简单基线与等预算协议

至少逐项实现以下可行决策，不能只选一个弱随机策略：

| 基线 | 它排除的伪增量 |
|---|---|
| 完整历史的被动残差/阈值、序列分类器，诊断后最优修复 | 信息早已存在，VLM读不出而已 |
| 固定重试、固定每一种 repair、双修复/全修复、两种升级顺序 | 额外尝试或廉价通用修复已足够 |
| 固定最佳探针、随机探针、离线贪心信息增益 | 不需要按当前失败自适应选动作 |
| 有限库经验 Bayes：同训练集估计 P(Z|H,p) 与 repair成功/代价，穷举 p+repair 的期望总成本 | 故障/动作少时学习复杂策略只是在学查表 |
| 小规模 belief-state DP 或其有限时域穷举，纳入失败观测更新与 probe副作用 | 经典排障/dual-control 已能解决决策结构 |
| FIERL式：同被动诊断器，同观测，诊断reward与跟踪/位移约束 | 新学习机制是否只是既有RL主动输入设计 |
| oracle H、oracle最佳探针、oracle合法修复 | 辨识/探针选择/执行各自的剩余差距；oracle非可部署竞争基线 |

共同预算不能只按“attempt 数”。所有方法统一限制并记录：总墙钟时间、控制步、累计/峰值位移、接触次数、任务重置、推理延迟、失败代价，以及探测用掉的机会。探针消耗的动作必须从恢复预算扣除；baseline 也可把同样资源用于重试或升级。训练数据、故障真值、模型/诊断器、超参搜索与先导真机调参次数一致。A100训练成本另报，不把 sim oracle数据只给本方法。

预登记主指标应为 budget-B 内恢复率与每成功总成本，而非文本解释质量。按夹具/物体/故障配置分组切分，避免同一装置照片泄漏；报告配对差值与区间。小样本下优先说估计不确定，不能把“未显著不同”当等效。若要宣布简单策略已足够，使用预定等效/非劣界。

## 10. 必须终止 C 的结果

满足任一条就停止以此为主论文方法，不靠加模块续命：

1. **完整被动历史已能可靠选择同样修复**；失败只是选错图像/漏记时间戳，主动信息的前提不存在。
2. **全修复或廉价升级在相同墙钟/位移/接触预算下非劣**；Which Hand 已展示这类风险，不可事后把它排除。
3. **固定探针或有限库经验Bayes非劣于拟议学习策略**，且所谓新机制只剩平台与模型替换；核心方法新颖性和必要性都失败。
4. **有仿真分离，但真实 RGB/q响应不分离或修复排序不反转**；仿真/真机没有验证同一命题。
5. **只有通过故意屏蔽廉价现有信息、禁止合法修复或增加未确认传感器才能成立**；不符合本项目约束。
6. 找到同信息假设、同预算、同辨识量和同机制的一级来源；即使本地结果提高，也不能继续主张原创。

## 11. 命题—证据审计与下一决定

| 命题 | 所需证据 | 当前证据 | 缺口/风险 |
|---|---|---|---|
| 主动辨因本身是核心创新 | 与AFD/排障/近期机器人在机制上有本质差异 | 已有多条直接覆盖 | **不通过，停止宽泛主张** |
| 当前SO-101任务被动不可辨识且修复互斥 | 结构性配对反例+全历史泄漏审计+repair矩阵 | 无实物/模拟验证 | 只能做否证先导 |
| 自适应探针有必要 | 固定探针、全部修复、经验Bayes、DP等预算比较 | 无结果 | 不能默认需要学模型 |
| 新机制优于已有主动诊断 | 新机制明确改变某决策/计算界，且对应强消融 | **尚未提出有证据支撑的新机制** | 不宜立项或大矩阵 |
| 低成本真机验证同命题 | 同故障、同观测、同预算、同repair矩阵 | 无结果 | 演示不算通过 |

**推荐：停止当前 C 的立项式推进；如要保留，只批准一个极小反例/基线先导，用于迅速决定换题。** 本报告没有证明所有可能的主动诊断研究都已完成；它证明当前拟议的通用问题与主要机制已不足以支撑原创主张。剩余缺口不能只写成“现有方法没在SO-101实测”，更不能把一串待回答的问题当成已经找到新机制。

待续核验范围：Google Scholar人工可用时的引用/被引链；2026最新机器人主动诊断；已知非线性/部分可观测/决策损失AFD的更完整文献。它们可能继续缩小空间，不能反向作为当前通过的理由。
